- doc updates
- future consumer planning
- independent cleanup/proof tasks
- But I will not run parallel implementation passes that depend on unsettled VT truth.
For subagents, yes, I’m ready to run them with near-zero room for guessing by always pinning:
- exact checkpoint name
- exact source files
- exact reference files
- exact in-scope and out-of-scope semantics
- exact proof target

- explicit “do not add ABI / do not add new layer / do not bypass owner” constraints when coding
