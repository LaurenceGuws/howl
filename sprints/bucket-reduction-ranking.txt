## Current Bucket Inventory

Public types and aliases:

- `Surface`: legacy terminal-surface bucket. True owner split is `term.zig` for terminal surface ownership, `tab.zig` for pane/chrome containment, and specialized owners below.
- `Surface.PresentDamage`: render/present damage alias. True owner candidate: `texture/egl_swap.zig` or `render/` public surface-present type. Current callers mostly `tab.zig`/`events/event.zig` through `RuntimeTab.PresentDamage`.
- `Surface.TurnStep`, `Surface.TurnResult`: render-turn/present result vocabulary. True owner candidate: `render/` or `term.zig` if kept as terminal-surface owner API; likely paired with render-turn extraction.
- `Surface.CursorFacts`: cursor cadence/render aggregation. True owner candidate: `cursor/` with host render cadence details staying in `render/surface_retained.zig` only by explicit API.
- `Surface.MouseHandlingOutcome`: alias to input processor outcome. True owner candidate: remove alias; callers should use `input/processor.zig` or owner-specific outcomes directly.

Field groups:

- Embedded terminal core: `term: HowlTerm`. True owner: `term.zig`.
- PTY runtime lifecycle: `progress`, `live`, `init`, `deinit`, `startRuntime`. True owner: `pty/` plus `term.zig` for lifecycle entry points; host thread ownership stays outside PTY.
- Texture resources: `term_texture`, `render_surface_textures`, `uploadRenderSurface`, texture deletion. True owner: `texture/term.zig`, called by `term.zig` or a render-turn owner.
- Host config and input handles: `conf`, `input`, `event_loop`. True owner: likely `tab.zig`/host runtime for `input` and `event_loop`; `term.zig` may retain `conf` values only where needed for terminal surface policy.
- Title cache: `title_buf`, `title_len`, `title_generation_seen`, `titleSlice`, `titleGeneration`, `refreshTitle`, `titleFromLaunch`. True owner: `term.zig` or small `vt/title` integration wrapper if title cache stays terminal-owned.
- Surface layout state: `surface_layout`, `resize`, `syncPendingSurfacePixels`, `syncSurfaceLayout`, `readSurfacePixels`, `syncPendingSurfacePixelsLocked`, `surfacePointCell`. True owner: `render/surface_layout.zig` for operations; stored by `term.zig` unless pane chrome owns pending pixel size.
- Font size state: `font_size_px`, `default_font_size_px`, `adjustFontSize`, `toggleStressFontSize`, `resetFontSize`. True owner: `render/fonts.zig` for policy helpers; state likely `term.zig` because it affects terminal surface layout.
- Focus state: `window_focused`, `widget_focused`, `setWindowFocused`, `setWidgetFocused`, `syncInputFocus`. True owner: `tab.zig` decides pane focus; `term.zig` publishes terminal focus and owns terminal consequences.
- Scrollbar state: `scrollbar`, scrollbar input callbacks, frame placement use in `tab.zig`. True owner: `scroll_bar.zig`; pane chrome in `tab.zig` owns placement and visual chrome, term owns scrollback consequence.
- Link state: `links`, link hover/selection callbacks. True owner: `render/links.zig`; unclear whether pane chrome or term owns hover state after split, so lower rank.
- Selection state: `selection`, selection mouse callback. True owner: `selection.zig`; selected through input processor callback, likely term-owned because it mutates VT selection.
- Cursor state: `cursor_blink`, `cursor_position_sequence`, `cursor_client_moved_at_ns`, `cursor_render_info`, `cursor_trail`, `cursor_text_blinking`, `cursor_render`, cursor facts/cadence methods. True owner: `cursor/`, with `term.zig` owning terminal cursor surface consequences.

True owner: split into `term.zig`, `pty/session.zig`, `render/surface_layout.zig`, `render/fonts.zig`, and `vt/` initialization helpers. This is broad and lower-ranked.
- Render turn and present: `wantsRenderTurn`, `renderTurn`, `noteRenderTurn`, `notePresentSubmitted`, `completePresent`, `renderTurnAdmission`, `DriveResult`, `driveRenderLocked`, `submitPrepared`, `submitPreparedLocked`, `SubmitPreparedResult`, `idleDrive`, `failedUploadSubmit`, `stalePreparedUploadSubmit`, `uploadRenderSurface`, `submitStep`, `submitDriveResult`, `notePreparedStep`. True owner: `cursor/` and `term.zig` as surface caller.
- Input adapter: `terminalOwnsMouse`, `termInput`, `selectedSurface`, callback functions `resetCursorBlinkActivitySelected`, `writeBytesToPtySelected`, `writeKeyToPtySelected`, `writeMouseToPtySelected`, `surfacePointCellSelected`, `processScrollBarMouseSelected`, `clearHoveredLinkSelected`, `scrollViewportByWheelSelected`, `processSelectionMouseSelected`, `processLinkMouseSelected`. Test hooks:

- `TestingHooks.upload_render_surface`, `before_render_submit`, `observe_submit_execution`: render/texture submit tests. True owner candidate: local test hooks in extracted render-turn owner or texture submit test helper.

Caller classes:

- `tab.zig` imports `bucket2.zig` as `TerminalSurface`, stores panes, drives layout/chrome/focus/input and forwards render/present calls.
- `events/event.zig` reaches bucket through `RuntimeTab` and therefore mostly through tab APIs, not direct bucket access.
- `host_test_root.zig` still imports bucket as `TerminalSurface` for tests and source guard tests.
- `bucekt2_test.zig` directly tests bucket render/cursor/submit behavior and will need test migration per slice.
- `input/processor.zig`, `selection.zig`, `render/links.zig`, `scroll_bar.zig` currently receive callback/context shapes rooted in bucket `Surface`; these are larger redesign seams.

- Old bucket symbols/callers: fields `title_buf`, `title_len`, `title_generation_seen`; methods `titleSlice`, `titleGeneration`, `refreshTitle`; helper `titleFromLaunch`; callers `tab.zig` `titleSlice`, `titleGeneration`, `events/event.zig` through tab title sync; initialization in `initial`, `initTerm`, `startRuntime`.
- Target owner files/symbols: `term.zig` owns title cache in `Term` or a small `Title` data shape if unavoidable; `vt/title.zig` remains low-level title buffer owner.
- Expected file changes: `term.zig`, `bucket2.zig`, `tab.zig`, `bucekt2_test.zig` if title setup helpers exist.
- Tests to add/delete/update: add/keep term-level title fallback/generation tests if existing coverage is moved; update tab title tests to read `runtime_pane.term` or term title API; delete bucket title tests if any.
- Stale grep gates: no `title_buf|title_len|title_generation_seen|titleFromLaunch|refreshTitle` in `bucket2.zig`; no new wrapper in bucket.
- Worker-readiness: high. Compact state, clear terminal owner, low reference ambiguity.
