# Host Main Scheduler Sprint

Purpose:

- Define and implement the main host scheduler owner.
- This sprint embodies Alacritty's UI/event/render scheduling thread using Howl nouns.

Scope:

- Add or reshape `howl-linux-host/src/events/scheduler.zig`.
- Own host wait deadlines, frame cadence, redraw/dirty admission, terminal wake coalescing, and event-loop wait intent.
- Coordinate `window/`, `texture/`, `layout/`, PTY wake handoff, frame construction, present submission, and present retirement without owning those lower states.

Reference pressure:

- Alacritty `scheduler.rs`: pending timers, `Timer.deadline`, closest deadline.
- Alacritty `event.rs`: scheduler deadline to `ControlFlow::WaitUntil` or `Wait`.
- Alacritty `window_context.rs`: dirty/redraw request and display interaction.

Non-goals:

- No `Display` or `Context` nouns.
- No new compatibility layer.
- No ownership of VT, PTY internals, retained render state, texture resources, pane placement math, or terminal-local cursor/selection/link/scrollbar mutation.
- No Ghostty-style renderer thread split unless separately proven.

Proof requirements:

- Comments explain why the main host scheduler owns each scheduling decision.
- Tests prove wait-deadline selection, wake-not-drive-admission, frame cadence admission, and dirty/redraw consequences.
- `zig fmt --check build.zig src`, `zig build check`, `zig build test:unit`, and `git diff --check` pass for every accepted slice.
