# Host Loop Bucket Deletion

Purpose:

- Delete `howl-linux-host/src/buckets that must die/host_loop_bucket.zig` by moving each responsibility into a real host owner.
- Preserve behavior while removing the false `Processor` bucket from the public host path.
- Keep this slice focused on the host-main bucket only. Do not start the `bucket2.zig` terminal-instance split in this slice.

Current receipt:

- `events/event.zig` was moved as-is to `howl-linux-host/src/buckets that must die/host_loop_bucket.zig`.
- The host compiles after the move.
- The narrow external seam proves this file was not a broad event subsystem:
  - `howl-linux-host/src/events.zig` re-exports `event` from the bucket and exposes `Processor`.
  - `howl-linux-host/src/main.zig` constructs and runs `Events.Processor`.
  - `howl-linux-host/src/buckets that must die/bucekt2_test.zig` imports the bucket only for present-reason proof.
  - Real lower owners already exist for event transport, timer scheduling, window, surface-present trigger, layout, texture, tab, and input.

Non-negotiables:

- No compatibility aliases or shims.
- No renamed bucket under a cleaner name.
- No new `Processor`, `Context`, `State`, `Runtime`, `Manager`, `Engine`, `Controller`, `Options`, `Facts`, `Snapshot`, or generic bucket type.
- Do not move or redesign `howl-linux-host/src/buckets that must die/bucket2.zig` in this slice.
- Do not move terminal-instance PTY/VT/render sequencing into `term.zig` in this slice.
- Do not change behavior intentionally.
- Do not move texture/GL ownership out of `texture/`.
- Do not move tab/pane policy out of `tab.zig` except for host-main command routing that currently lives in the bucket.
- Keep function signatures on one line unless `zig fmt` forces otherwise.

Target owner files:

- `howl-linux-host/src/host_loop.zig`
  - Owns the main/window loop turn.
  - Owns `run`, one turn of host progression, quit/pump control, wait-event collection, typed host event dispatch, and the calls into input/tab/render owners.
  - Does not own tab lifecycle details, terminal input details, render frame construction, texture upload, or present frame construction.

- `howl-linux-host/src/host_input.zig`
  - Owns host-loop input admission and forwarding into existing tab/terminal owners.
  - Owns input policy configuration, focus propagation, terminal input forwarding, window resize propagation, and cursor timer dispatch.
  - May call `tab.zig`, `input.zig`, `layout/*`, `events/window.zig`, and `events/scheduler.zig` as needed.
  - Does not own VT, PTY, render retained state, texture, or tab lifecycle.

- `howl-linux-host/src/host_tabs.zig`
  - Owns host-main tab commands and active-tab selection routing.
  - Owns open tab, close tab, select tab, focus pane, split pane, active-tab problem handling, tab title aggregation, and paste routing.
  - Uses existing `tab.zig` as the runtime tab/pane owner; does not steal pane storage or tab invariants.
  - Does not own texture upload, present policy, input queue internals, or terminal render sequencing.

- `howl-linux-host/src/host_render.zig`
  - Owns host-main render/present orchestration.
  - Owns active tab render turn orchestration, pane surface readiness, upload of prepared terminal panes into `texture/frame.zig`, present reason selection, present frame construction, and present submission call path.
  - Does not own `texture/frame.zig` resources, terminal retained state internals, layout policy, or tab/pane storage.

Expected deletion:

- Delete `howl-linux-host/src/buckets that must die/host_loop_bucket.zig` by the end of this slice.
- Remove `Events.Processor` from `howl-linux-host/src/events.zig` unless a true owner still justifies a public alias. Prefer importing the true owner directly from `main.zig`.
- Update tests so no file imports `host_loop_bucket.zig`.

Expected import shape:

- `howl-linux-host/src/main.zig` should construct the real host-loop owner from `host_loop.zig` directly.
- `howl-linux-host/src/events.zig` should continue to curate only true `events/*` owners:
  - `event_loop`
  - `frame_timer`
  - `scheduler`
  - `window`
  - `window_wake`
  - surface-present module if currently exported elsewhere
- `howl-linux-host/src/host_test_root.zig` should import true host owner test surfaces, not bucket paths.
- `howl-linux-host/src/buckets that must die/bucekt2_test.zig` should not import host-loop internals. If it still needs present-reason proof, move that proof to `host_render.zig` tests or expose a small testing namespace from the true owner.

Suggested cut order:

1. Move present-frame and present-reason code from `host_loop_bucket.zig` into `host_render.zig` with owner comments and tests.
2. Move tab command/lifecycle code into `host_tabs.zig` with owner comments and tests.
3. Move input/focus/resize/cursor-dispatch code into `host_input.zig` with owner comments and tests.
4. Move remaining main-loop turn code into `host_loop.zig` and make `main.zig` use it directly.
5. Delete `host_loop_bucket.zig` and remove all imports/re-exports that mention it.
6. Run stale-name searches for `host_loop_bucket`, `Events.Processor`, `event.Processor`, and `events/event.zig`.

Required proof:

- `zig fmt --check build.zig src`
- `zig build check`
- `zig build test:unit`
- `git diff --check` from `howl-linux-host`
- `git diff --check` from repository root

Reviewer checklist:

- The bucket file is deleted.
- No new bucket or generic owner replaces it.
- Every new file has a narrow owner comment explaining what it owns and does not own.
- `host_loop.zig` remains the control spine and calls lower owners instead of absorbing their details.
- `host_render.zig` does not own texture resources or terminal retained internals.
- `host_tabs.zig` does not own runtime pane storage beyond routing commands to `tab.zig`.
- `host_input.zig` does not own VT/PT/render state.
- `events.zig` no longer makes the bucket look like a real event subsystem.
- Existing `bucket2.zig` remains a known bucket for a later slice, not opportunistically edited beyond compile fallout.
