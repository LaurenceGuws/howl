# Current Slice: Rename Render Session Work State ABI

Owner: workspace root.

Purpose:

- Break the render C ABI to replace vague pending-state vocabulary with
  session-work-state vocabulary.
- The ABI reports render text-session work readiness: source, prepare, and submit work.
- No aliases, no compatibility shims, no old names.

## ABI Changes

In `howl-render/include/howl_render.h`, rename without old aliases:

- `HowlRenderPendingState` -> `HowlRenderSessionWorkState`
- `howl_render_text_session_pending_state` -> `howl_render_text_session_work_state`

Keep struct fields unchanged:

- `status`
- `source_pending`
- `prepare_pending`
- `submit_pending`
- `reserved0`

## Render Source Changes

- Rename `howl-render/src/pending_state.zig` to `howl-render/src/work_state.zig`.
- Update `howl-render/src/libhowl_render.zig` to import `work_state.zig`.
- Export `work_state.workState` as `howl_render_text_session_work_state`.

Boundary symbols:

- `pendingState` -> `workState`
- `pendingStateOut` -> `sessionWorkStateOut`
- `pendingStateFailure` -> `sessionWorkStateFailure`

Internal owner symbols:

- Delete `source_prepare.PendingState` from `howl-render/src/source/prepare_request.zig`.
- Add `SessionWorkState` in `howl-render/src/session/text.zig`.
- Rename `TextSessionOwner.pendingState` -> `TextSessionOwner.workState`.
- Add `SubmittedWorkState` in `howl-render/src/session/submitted.zig`.
- Rename `Submitted.pendingState` -> `Submitted.workState`.

## Host Changes

Update `howl-linux-host/src/terminal/render/retained.zig`:

- `c.HowlRenderPendingState` -> `c.HowlRenderSessionWorkState`
- `c.howl_render_text_session_pending_state` -> `c.howl_render_text_session_work_state`
- `State.pending(...)` -> `State.workState(...)`

Update `howl-linux-host/src/terminal/context.zig`:

- `self.term.render.pending(...)` -> `self.term.render.workState(...)`

## Tests

Update `howl-render/src/test/ffi.zig`:

- Import `../work_state.zig`.
- Use `c.HowlRenderSessionWorkState`.
- Call `work_state.workState`.

Preserve existing missing-handle and invalid-argument behavior.

## Invariants

- Behavior is unchanged.
- Session work state remains the aggregate of render-owned source, prepare, and submit work.
- Host-owned present/bootstrap work stays in host `render_retained.WorkState`.
- Source prepare does not own submit work.
- No aliases or old typedefs.
- No `types.zig`.
- No `manager`, `controller`, `runtime`, `flow`, `pipeline`, or `queue` owner.
