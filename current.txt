# Current Slice: Graphics Virtual Placement Forwarding Deletion

Owner: howl-render and howl-linux-host.

Sprint scope: graphics deletion.

## Goal

Delete or quarantine Howl-only render/host forwarding of virtual placements from decoded
graphics publication. Render should consume renderable placements, not Kitty virtual
placement prototypes.

## Delegation Requirement

- Main agent must not implement this slice directly.
- Seed a worker with this file, the render/host audit findings, exact source/reference
  paths, and the invariants below.
- Seed a reviewer after worker output and reject any diff that broadens into ABI removal,
  generated placement materialization, VT placeholder semantics, or render scheduling.

## Required Work

- Worker edits only render/host graphics forwarding paths unless a stop condition is hit.
- Remove host dependence on forwarding VT virtual placements into render publication.
- Make render ignore or stop validating virtual placement spans in the decoded publication
  path if they are currently stale inputs.
- Preserve public render ABI layout unless deletion is impossible without an explicit ABI
  break decision.
- Do not touch VT placeholder-run/generation behavior.
- Do not add a replacement system.

## Candidate Paths

- `howl-render/include/howl_render.h`
- `howl-render/src/frame/queue.zig`
- `howl-render/src/frame/surface_text.zig`
- `howl-render/src/frame/surface_text_ffi.zig`
- `howl-linux-host/src/terminal/vt/surface.zig`
- `howl-linux-host/src/terminal/render/retained.zig`
- `howl-linux-host/src/terminal/render/abi.zig`
- `howl-linux-host/src/terminal/vt/abi.zig`

## Reference Constraints

- Kitty virtual refs are prototypes and are not rendered directly; render uses real
  non-virtual refs/cell images.
- Ghostty exposes virtual placeholder iteration internally, not as render ABI forwarding.
- Howl render should receive renderable placements only.

## Invariants

- Rendered physical/generated placements remain unchanged.
- Public ABI layout remains unchanged unless worker stops and reports that deletion needs
  explicit ABI break approval.
- Host no longer treats virtual placement forwarding as render truth.
- No VT, FFI, or placeholder-run public behavior changes.

## Tests Required

- Run targeted render/host tests discovered by the worker.
- Run root `zig build --summary all` if feasible.
- Root and touched submodules `git diff --check`.

## Stop Conditions

- Stop if deleting forwarding requires public ABI layout removal.
- Stop if this requires generated cell-ref/materialization replacement.
- Stop if VT placeholder-run/generation semantics must change.
- Stop if render scheduling or retained-frame architecture must change.
