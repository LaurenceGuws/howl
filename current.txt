# Current Slice: VT Graphics Placement Kind Replacement

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` item 4 after placement-ref research.

## Goal

Match Kitty's single-ref namespace for nonzero placement ids without changing ABI: a physical and virtual placement with the same image id and client placement id are the same ref being updated, not two independent refs.

## Target Files

VT only:

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- Keep `howl_vt.h`, render, and hosts unchanged.
- Preserve image publication ABI and payload-copy behavior.
- For nonzero `p=`, `a=p,U=1` replaces an existing physical placement with the same `(image_id, placement_id)` instead of adding a duplicate virtual placement.
- For nonzero `p=`, physical `a=p` replaces an existing virtual placement with the same `(image_id, placement_id)` instead of adding a duplicate physical placement.
- Parent links that point at a converted placement id remain pointed at the same client ref and update their physical/virtual parent kind when possible.
- Anonymous `p=0` placement behavior remains unchanged; multiple anonymous placements are still allowed.
- Delete selectors and quota placement protection continue to treat the converted ref as one live placement.
- Existing generated-placeholder, virtual-placement, quota, delete-selector, image-number, frame loading, frame compose, and replacement behavior remains green.

## Hard Constraints

- Do not edit render or host.
- Do not edit `howl-vt/include/howl_vt.h`, `howl-vt/src/ffi.zig`, or `howl-vt/src/terminal.zig`.
- Do not introduce the full internal id/ref/cache rewrite or persistent generated cell refs.
- Do not change placement identity or render-facing publication structs.
- Do not solve anonymous `image_id == 0` multi-image identity in this slice.
- Do not solve omitted-parent `Q=0` drift with internal ref ids in this slice.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- Physical placement converted to virtual by same nonzero `p=` leaves physical count `0` and virtual count `1`.
- Virtual placement converted to physical by same nonzero `p=` leaves virtual count `0` and physical count `1`.
- Repeated physical/virtual conversions do not grow total placement count or duplicate replies.
- Anonymous `p=0` physical and virtual placements do not replace each other.
- Child placements referencing a converted nonzero parent keep resolving through the updated parent kind where possible.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct replacement semantics require full internal ref ids or persistent generated cell-ref storage, stop and report the exact dependency instead of widening the slice.
