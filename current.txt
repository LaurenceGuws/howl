## Required Diagnostic Shape

- Copy only scalar diagnostics; never retain V0 frame/span/upload byte pointers.
- Record V0 frame token and span counts: creates, uploads, retires, commands,
  upload byte total.
- Record churn shape: same-frame create/upload/use/retire count,
  persistent-resource reuse count, resources created without surviving next frame,
  creates per visible command.
- Record resource slots: live, retired, empty, max live, max retired.
- Record host GL side-effect counts separately from render spans:
  `glGenTextures`, `glTexImage2D`, `glTexSubImage2D`, `glDeleteTextures`.
- Record failure buckets: invalid spans, invalid command shape, invalid order,
  unsupported resource/format, upload bounds, tombstone value reuse, capacity,
  GL error.
- Record timings: V0 realization microseconds, full RGBA upload microseconds,
  `SDL_GL_SwapWindow` microseconds. Do not use `glFinish` as a diagnostic fence.
- Record GL state samples around V0 phases and full RGBA upload:
  `GL_TEXTURE_BINDING_2D`, `GL_UNPACK_ALIGNMENT`, `GL_UNPACK_ROW_LENGTH`,
  and `glGetError()`.
- SDL current-context/current-window/main-thread readiness checks belong to
  `present.zig`/`window.zig`, not `term_texture.zig`.
- Optional A/B gate may skip only live V0 GL realization while preserving V0 frame
  production, scalar diagnostics, software oracle/resource-plan probes, full RGBA
  upload, submit, and presentation. This gate is evidence only, not product behavior.

## User GUI Review Matrix

- `lll`: should still report command not found if no shell alias/binary exists.
- `l`: must not freeze; record whether V0 counters spike before freeze if it does.
- `btop` warning mode: should remain responsive; record counters.
- `btop` normal draw mode: record whether freeze correlates with creates/uploads,
  upload bytes, tombstones, GL errors, realization time, or swap time.
- Resize/font increase: record whether unfreeze correlates with reduced V0 counts or
  return to warning-screen rendering.

## Stop Conditions

- Stop if diagnostics require changing the render ABI/header.
- Stop if diagnostics require V0 command drawing or replacing full RGBA.
- Stop if the fix depends on treating `glDeleteTextures()` as protocol ack.
- Stop if resource ID reuse needs ack/removal policy; draft that contract first.
- Stop if tombstone retention or removal policy is ambiguous.
- Stop if logs would be unbounded or per-byte/per-cell spam.
- Stop if SDL current-window, current-context, main-thread, or GL global-state
  ownership remains ambiguous after reading the SDL/OpenGL references.
- Stop after one diagnostic slice and user GUI review; do not roll directly into a
  fix without a reviewed follow-up slice.
