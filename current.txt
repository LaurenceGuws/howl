# Current Slice: Extract VT Selection Projection From FFI

Owner: `howl-vt`.

Purpose:

- Move C-free VT selection projection/copy behavior out of `howl-vt/src/ffi.zig`.
- Preserve current coordinate semantics exactly as an honest temporary Howl stopgap.
- Keep C ABI translation in `ffi.zig` and keep Ghostty-style tracked selection as a later screen/page proof gap.

## Source Changes

Exact files:

- Edit `howl-vt/src/ffi.zig`.
- Create `howl-vt/src/selection/projection.zig`.
- Edit `howl-vt/src/screen_set.zig` only if a C-free row/content helper truly belongs there.
- Do not edit `howl-vt/include/howl_vt.h`.
- Do not edit public C export names.

## Required Shape

Move out of `ffi.zig`:

- `selectionRowSource`
- `selectionContentEndExclusive`
- `visibleSelectionRow`
- `visibleSelectionRange`
- `copySelectionText`

Create `howl-vt/src/selection/projection.zig` with exact C-free selection projection/copy ownership:

- `pub const Range = struct { start: u16, end_exclusive: u16 }`
- `pub fn rowSource(screen_state: *const screen_set.Set, row: i32) ?screen_set.RowSource`
- `pub fn contentEndExclusive(screen_state: *const screen_set.Set, row: i32) u16`
- `pub fn visibleRow(view: screen_set.View, row: u16) i32`
- `pub fn visibleRange(view: screen_set.View, selected: state.TerminalSelection, row: u16) ?Range`
- `pub fn copyText(allocator: std.mem.Allocator, screen_state: *const screen_set.Set, selected: ?state.TerminalSelection) ![]const u8`

In `ffi.zig`, retain only:

- handle casts
- C status mapping
- C buffer validation/copying
- final writes to `FfiSurfaceCell.attrs.selected` by applying ranges returned from `selection/projection.zig`

## Non-Goals

- Do not introduce Ghostty pins.
- Do not redesign selection ABI.
- Do not change history/live/visible coordinate semantics.
- Do not change exported `howl_vt_*` functions.
- Do not move screen/page storage.
- Do not introduce `HowlVt*` or `Ffi*` names in `selection/projection.zig`.
- Do not create compatibility aliases, module buckets, `types.zig`, `api.zig`, or `abi.zig`.

## Invariants

- History rows remain addressed by negative selection rows.
- Alternate screen selection copy/projection must not read primary history.
- Visible selection marking remains based on `screen_set.View.rowSource`.
- End-column handling remains inclusive from user endpoint to exclusive internal range.
- Empty rows and space-only rows keep current copy/projection behavior.
- Copied text allocation remains caller-owned through the terminal allocator; FFI still copies into the C caller buffer and frees the owned slice.
- This slice is a Howl stopgap, not Ghostty-equivalent tracked selection.

## Required Tests

Preserve existing tests:

- FFI selection query/copy history-aware behavior.
- FFI surface selection viewport/content hugging behavior.
- `terminal_surface.zig` alternate-screen selection clear behavior.

Add or preserve tests proving:

- History-to-live selection copy still returns the same text and visible selected cells.
- Alternate screen with primary history active does not copy/project primary history from negative rows.
- Selection copy short-buffer behavior remains unchanged if touched.

## Stop Conditions

- Stop if extraction requires importing C ABI structs into `selection/projection.zig`.
- Stop if coordinate semantics, C enum values, C structs, or exported names must change.
- Stop if alternate-screen selection copy/projection cannot be proved without deeper screen/page work.
- Stop if the new owner becomes a vague bucket or reintroduces behavior under a different FFI helper name.
- Stop if allocation ownership for copied text is ambiguous after movement.
