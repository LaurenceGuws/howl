# Current Slice: Reject Both Image Id Forms

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after image-id/image-number validation research.

## Goal

Match Kitty behavior by rejecting graphics commands that specify both lowercase `i=` image id and uppercase `I=` image number.

## Target Files

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- Any graphics command with both `cmd.image_id != 0` and `cmd.image_number != 0` rejects before command-specific mutation.
- Failure reply uses `EINVAL:Must not specify both image id and image number` unless quiet failure suppression applies.
- Rejection stores no image/frame/placement and does not mutate existing graphics state.
- Existing commands with only `i=`, only `I=`, or neither keep current behavior.

## Hard Constraints

- Do not change ABI, render, host, parser, terminal, FFI, or build files.
- Do not change parser validation; this is VT command validation before mutation.
- Do not change successful upload, query, place, delete, animation, frame, media normalization, quiet semantics, EBADPNG behavior, PNG decoder behavior, zlib/compressed raw, direct/indirect media behavior, storage quota, composition, or generated placeholder behavior.
- Do not replace retained base64 model truth or identity/ref storage model in this slice.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- Direct transmit with both `i=` and `I=` rejects with `EINVAL` and stores no image.
- Place with both `i=` and `I=` rejects with `EINVAL` instead of `ENOENT` and stores no placement.
- Animation/control or frame path with both ids rejects before mutation.
- `q=2` suppresses the mutual-exclusion failure and still does not mutate state.
- Existing valid image-number-only behavior continues to pass.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct behavior requires parser changes, identity/ref storage rewrites, host/runtime changes, render changes, ABI changes, or broader command validation refactors, stop and report the exact dependency instead of widening the slice.
