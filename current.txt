## Target Shape

`howl-render/src/ffi.zig` owns only:

```zig
pub const c = @cImport({
    @cInclude("howl_render.h");
});
```

All other C boundary files use:

```zig
const c = @import("ffi.zig").c;
```

`libhowl_render.zig` exports from noun files, not from `ffi.zig`.
