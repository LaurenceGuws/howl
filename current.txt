## Purpose

Delete `howl-render/src/protocol_v0/` as an internal source bucket by moving the
emitter and realizer to exact owner paths.

Public ABI `protocol_v0` vocabulary is preserved in this slice.

## Allowed Files

- `howl-render/src/protocol_v0/emit.zig`
- `howl-render/src/protocol_v0/realize.zig`
- `howl-render/src/prepared/v0_frame_emitter.zig`
- `howl-render/src/render/v0_frame_realizer.zig`
- `howl-render/src/prepared/owner.zig`
- `howl-render/src/session/text.zig`
- `howl-render/src/test/unit/root.zig`
- `howl-render/src/test/unit/render_api_v0_oracle.zig`
- `howl-render/src/ffi/protocol_v0.zig`

No other files are in scope.

## Required Shape

- Move `howl-render/src/protocol_v0/emit.zig` to
  `howl-render/src/prepared/v0_frame_emitter.zig`.
- Move `howl-render/src/protocol_v0/realize.zig` to
  `howl-render/src/render/v0_frame_realizer.zig`.
- Delete `howl-render/src/protocol_v0/` after it is empty.
- Update `howl-render/src/prepared/owner.zig` to import
  `v0_frame_emitter.zig`.
- Update `howl-render/src/session/text.zig` to import
  `../prepared/v0_frame_emitter.zig`.
- Update `howl-render/src/test/unit/root.zig` to import
  `../../render/v0_frame_realizer.zig` and
  `../../prepared/v0_frame_emitter.zig`.
- Update `howl-render/src/test/unit/render_api_v0_oracle.zig` to import
  `../../prepared/v0_frame_emitter.zig` and
  `../../render/v0_frame_realizer.zig`.
- Update `howl-render/src/ffi/protocol_v0.zig` test import only, from the old
  realizer path to `../render/v0_frame_realizer.zig`.
- Inside moved `prepared/v0_frame_emitter.zig`, update its local realizer import
  to `../render/v0_frame_realizer.zig` and adjust relative imports only as
  required by the move.
- Preserve file-local emitter tests, file-local realizer tests,
  oracle/equivalence tests, and ABI layout/diagnostic tests.

## Non-Goals

- Do not rename public C ABI names, exported symbols, header names, diagnostics
  fields, or public ABI test assertions.
- Do not move or rename `howl-render/src/ffi/protocol_v0.zig`.
- Do not edit `howl-render/build.zig`.
- Do not edit host code.
- Do not add a compatibility shim or re-export under `src/protocol_v0/`.
- Do not rename internal prepared owner APIs such as `protocolV0Frame()` in this
  slice.

## Stop Conditions

- Stop if any owner path other than `prepared/v0_frame_emitter.zig` and
  `render/v0_frame_realizer.zig` is needed.
- Stop if public ABI symbols or host behavior must change.
- Stop if `ffi/protocol_v0.zig` must move or be renamed.
- Stop if `build.zig` needs modification.
- Stop if unit or ABI tests lose emitter, realizer, oracle, or ABI coverage.
- Stop if `src/protocol_v0/` would remain as a shim or re-export.
