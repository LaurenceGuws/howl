## Purpose

Implement the source-backed `event_loop.zig` plus concrete `polling/window_wake.zig` owner shape, removing SDL wait/poll/wake ownership from input.

## Orchestration Rule

- If ownership, naming, scope, test gates, or ABI consequences are under-specified, stop and report orchestration needed.
- Do not silently fill design gaps, broaden scope, choose new owner names, or turn an ambiguous path into implementation.

## Status

- `input/window.zig` to `input/wake.zig` landed, but the owner remains wrong.
- `input/wake.zig` to `app/wake.zig` is rejected.
- A cosmetic `event_loop.zig` move-only slice is rejected.
- The next acceptable plan must create a real event-loop boundary and a concrete tracked `polling/` owner file.

## Required Shape

- Create `howl-linux-host/src/event_loop.zig` as the host event-loop owner.
- Create `howl-linux-host/src/polling/window_wake.zig` as the concrete SDL window event-loop wake/poll/time/timer/semaphore owner.
- Do not create `polling/signal.zig` or `polling/ipc.zig` until Howl has product behavior and tests for those paths.
- Move SDL wait/poll/wake/quit/time/semaphore responsibilities out of `input/input.zig` and `input/wake.zig` in the first implementation slice.
- Retarget PTY wait-thread wake acknowledgement to the event-loop owner in the same implementation slice.
- Keep input event classification, key/mouse/text conversion, bounded queues, focus/geometry flags, and binding behavior in `input/input.zig` unless explicitly planned otherwise.
- Preserve centralized app control spine, bounded turns, and PTY wait-thread wake-only discipline.
- No ABI changes.

## Required First Implementation Tests

- Event-loop test: wake event is consumed and not classified as input.
- Event-loop test: quit event sets quit state and returns `.quit`.
- Event-loop test: bounded drain does not exceed `max_sdl_events_per_turn`.
- Event-loop test: `requestQuit()` sets quit and pushes wake through fake ops.
- Update existing PTY wait-thread tests so wake coalescing and acknowledgement target the event-loop wake seam, not input.
