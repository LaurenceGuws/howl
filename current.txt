# Current Slice: VT Graphics Stable Parent Refs

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` item 4 after placement-ref identity research.

## Goal

Bind relative placements to VT-owned parent ref identity without changing ABI, so parent references selected by `P=<image>,Q=0` do not drift when placement arrays are reordered or later refs are added/removed.

## Target Files

VT only:

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- Keep `howl_vt.h`, render, and hosts unchanged.
- Preserve image publication ABI and payload-copy behavior.
- Assign each physical and virtual placement a VT-internal ref id.
- Preserve the internal ref id when an existing nonzero client placement id is updated or converted between physical and virtual kind.
- Store relative parent links by internal parent ref id, while keeping public/client parent fields for ABI publication.
- `P=<image>,Q=0` selects the first live parent ref at creation time and remains bound to that ref even if other refs are later removed or arrays reorder.
- Parent chain resolution, cycle checks, descendant deletion, and virtual-parent resolution use internal parent ref identity where possible.
- Anonymous `p=0` placement behavior remains unchanged except that each anonymous placement receives a distinct internal ref id.
- Existing generated-placeholder, virtual-placement, quota, delete-selector, image-number, frame loading, frame compose, and placement-kind replacement behavior remains green.

## Hard Constraints

- Do not edit render or host.
- Do not edit `howl-vt/include/howl_vt.h`, `howl-vt/src/ffi.zig`, or `howl-vt/src/terminal.zig`.
- Do not introduce the full internal id/ref/cache rewrite or persistent generated cell refs.
- Do not change placement identity or render-facing publication structs.
- Do not solve anonymous `image_id == 0` multi-image identity in this slice.
- Do not expose internal ref ids through the C ABI.
- Do not make generated placeholder placements persistent refs in this slice.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- `P=<image>,Q=0` child remains anchored to the originally selected physical parent after another parent placement is removed/reordered.
- `P=<image>,Q=0` child remains anchored to the originally selected virtual parent after another parent ref is added or removed.
- Updating a nonzero parent placement preserves its internal ref id and keeps existing children attached.
- Converting a nonzero parent physical-to-virtual and virtual-to-physical preserves its internal ref id and keeps existing children attached through the updated kind.
- Deleting a parent placement removes descendants by internal parent ref, including anonymous parents where client `placement_id` is `0`.
- Existing placement-kind replacement tests remain green.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct stable parent behavior requires persistent generated cell-ref storage or render ABI changes, stop and report the exact dependency instead of widening the slice.
