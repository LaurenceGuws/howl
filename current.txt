# Current Slice: Remove Render FFI Publish Scratch

Owner: workspace root.

Purpose:

- Remove retained publication scratch and source publication policy from
  `howl-render/src/ffi.zig`.
- Keep `howl-render/include/howl_render.h` byte-for-byte unchanged.
- Follow the Alacritty-derived split: source owns VT-derived publication
  storage and validation; FFI exposes C spans and translates C status/fields
  only.

## Source Facts

- Alacritty `Term` owns source grid/damage and display borrows/adapts it.
- Howl `source/slot.zig` already owns retained `[]source_vt.SourceCell` storage.
- `HowlRenderPublishSlot.cells` remains `HowlVtSurfaceCell *` in the stable C ABI.
- Therefore source-owned retained cells are the temporary writable C publication
  span; FFI only casts and returns the span.

## Required Edits

In `howl-render/src/source/vt.zig`:

- Add source-owned validation:
  - `validateSourceCell(cell: SourceCell) !void`
  - `validateSourceCells(cells: []const SourceCell) !void`
  - `validateReservedSourceMeta(meta: ReservedSourceMeta) !void`
- Validate:
  - `codepoint <= std.math.maxInt(u21)`
  - `combining_len <= combining.len`
  - every active combining codepoint <= `u21`
  - `SourceColor.kind` is `0`, `1`, or `2`
  - indexed color value <= `u8`
  - rgb color value <= `u24`
  - underline style is `0...4`
  - `snapshot_seq != 0`
- Do not import C.

In `howl-render/src/source/slot.zig`:

- Keep `SourceSlot` as owner of retained `[]source_vt.SourceCell` storage.
- In `commitReservedSource()`:
  - validate `ReservedSourceMeta` through `source_vt`
  - validate retained source cells through `source_vt`
  - keep dirty validation/canonicalization in `source/damage.zig`
  - preserve retained-storage behavior

In `howl-render/src/surface/text.zig`:

- `SurfaceTextOwner.commitPublishSlot()` remains composition only:
  - call source slot commit
  - set cursor phase
  - pass source to prepare request owner
- Do not expose source-slot reservation internals to FFI.

In `howl-render/src/ffi.zig`:

- Delete invented FFI state:
  - `PublishScratch`
  - `ScratchMutex`
  - `publish_scratch_mutex`
  - `publish_scratch_entries`
  - `reservePublishScratch()`
  - `copyPublishScratch()`
  - `removePublishScratch()`
- Delete direct source publication policy:
  - no `owner.source_slot.reservedSource()`
  - no source cell validation loop
  - no `validatePublicationCellValue()`
- `reservePublishSlot()`:
  - call `owner.reservePublishSlot(cols, rows)`
  - return C writable cell span by casting owner-owned `[]source_vt.SourceCell`
    to `HowlVtSurfaceCell *`
  - return dirty spans directly
- `commitPublishSlot()`:
  - translate `HowlRenderPublishSlotCommit` to `source_vt.ReservedSourceMeta`
  - call `owner.commitPublishSlot(meta)`
  - map owner errors to C status
  - do not own cancel policy beyond public owner calls
- Add FFI-only compile-time ABI layout assertions proving the stable cast:
  - source cell size/alignment equals `c.HowlVtSurfaceCell`
  - offset equality for `codepoint`, `combining_len`, `combining`, `flags`,
    `fg_color`, `bg_color`, `underline_color`, `underline_style`, `attrs`,
    `link_id`
  - source color size/alignment/field offsets equal `c.HowlVtColor`
  - source attrs/flags size and offsets equal C
- Delete unused `cellValueIn()` and `byteSpanIn()` if no remaining callers.
