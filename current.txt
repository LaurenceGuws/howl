## Required Product Shape

- Add public V0 kind macros to `howl-render/include/howl_render.h` matching
  `docs/render-protocol-v0.md`.
- Extend `ffi/protocol_v0.zig` compile-time assertions for every new kind macro.
- Add `protocol_v0/realize.zig` as an internal module only.
- Realizer input is an already-formed `c.HowlRenderV0Frame`.
- Realizer output is caller-provided RGBA bytes.
- No heap allocation inside realization.
- Optional retained base is caller-provided and copied before commands.
- No C ABI export or host-visible production path.

## Required Semantics

- Validate `pixels.len == render_px.width * render_px.height * 4`.
- If base is present, validate same byte length and copy it.
- If base is absent, clear to `{0, 0, 0, 255}` like `clearSurfacePixels()`.
- Apply commands in list order.
- `CLEAR_RECT` and `FILL_RECT` blend exactly like `drawSolidRect()` and
  `blendPixel()`.
- `DRAW_SPRITE` supports only `SPRITE_ALPHA` and `SPRITE_COLOR` resources.
- Alpha sprite source RGB comes from command `color_rgba`; source alpha is
  `(color_rgba.a * alpha_byte) / 255` before source-over blend.
- Color sprite source RGBA comes from upload bytes; command `color_rgba` must be
  zero.
- Reject `DRAW_GLYPH_RUN` in all forms.
- Reject `GLYPH_ATLAS_ALPHA` and `GLYPH_ATLAS_COLOR` create/upload/use.
