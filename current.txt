# Current Slice: Truncate Indirect Raw Oversize

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after indirect raw explicit-size oversize research.

## Goal

Match Kitty/Ghostty behavior by ignoring extra bytes from uncompressed indirect raw graphics media when explicit `S=` is larger than the declared raw image dimensions require.

## Target Files

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- For uncompressed indirect raw uploads (`t=f`, `t=t`, or `t=s`, `c` omitted, `f=24` or `f=32`), retain and publish only `width * height * bytes_per_pixel` bytes.
- Explicit `S=` larger than the required raw byte count succeeds but ignores trailing bytes.
- Existing undersize validation remains unchanged.
- Omitted `S=` valid indirect raw behavior remains unchanged.
- Safe temp deletion and shared-memory unlink behavior remain unchanged.

## Hard Constraints

- Do not change ABI, render, host, parser, terminal, FFI, or build files.
- Do not change direct media behavior, direct chunk lifecycle, parser validation, or quiet response handling.
- Do not change undersize failure behavior.
- Do not change EBADPNG behavior, PNG mode behavior, zlib decompression behavior, storage quota, animation, delete/reset, composition, or generated placeholder behavior.
- Do not replace retained base64 model truth in this slice.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- File medium `t=f,S=5,s=1,v=1,f=24` over bytes `ABCXY` stores retained payload `QUJD` for `ABC` only.
- Temp-file medium `t=t,S=5,s=1,v=1,f=24` stores `QUJD` and still deletes a safe temp file.
- Shared-memory medium `t=s,S=5,s=1,v=1,f=24` stores `QUJD` and still unlinks the shared-memory object.
- Existing undersize and omitted-`S=` indirect raw tests continue to pass.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct behavior requires replacing retained base64 model truth, parser changes, host/runtime changes, render changes, ABI changes, or broad fixture rewrites, stop and report the exact dependency instead of widening the slice.
