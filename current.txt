## Research Questions

- What exact decoded byte ownership does Kitty use for direct, compressed, PNG, file,
  temp-file, shared-memory, root image, frame, and animation storage?
- What exact decoded byte ownership does Ghostty use for command parse, loading image,
  completed image, storage quota, and eviction?
- Which Howl C ABI contracts currently promise protocol/base64 payload bytes, and which
  host/render call sites depend on that promise?
- What is the smallest ABI-safe transition shape: parallel decoded-byte query APIs,
  versioned payload metadata, or a VT-internal decoded store with temporary base64
  publication?
- What tests prove the boundary without broad render/cache/quota redesign?
- Which future slice should be implemented first, and which files/symbols must it own?
