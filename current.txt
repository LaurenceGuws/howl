Owner: workspace root.

- Delete vague render submit “feedback” vocabulary from the C ABI and source.

## ABI Changes

In `howl-render/include/howl_render.h`, rename without old aliases:

- `HowlRenderSurfaceMetrics` -> `HowlRenderMetrics`
- `HowlRenderSurfaceHandle` -> `HowlRenderHostSurface`
- `HowlRenderSurfaceExecutionInput` -> `HowlRenderSubmitExecution`
- `HowlRenderSurfaceFeedback` -> `HowlRenderSubmitResult`

Prefer field vocabulary:

- `HowlRenderSubmitExecution.host_surface`
- `HowlRenderSubmitResult.host_surface`

Update submit function signatures to use:

- `const HowlRenderSubmitExecution *execution_in`
- `HowlRenderSubmitResult *result_out`

Do not change function names in this slice unless build requires it. The noun
cleanup here is type/result vocabulary only.

## Render Source Changes

Delete/rename `howl-render/src/surface_feedback.zig`:

- New file: `howl-render/src/submit_result.zig`
- `surfaceMetricsOut()` -> `metricsOut()`
- `surfaceFeedbackOut()` -> `submitResultOut()`
- `failedSurfaceFeedback()` -> `failedSubmitResult()`
- `executionInputIn()` -> `submitExecutionIn()`

In `howl-render/src/prepared/feedback.zig`:

- Rename internal nouns:
  - `RenderSurfaceHandle` -> `HostSurface`
  - `RenderSurfaceFeedback` -> `SubmitResult`
  - `RenderMetrics` -> `Metrics` if mechanical; otherwise do not leave
    `SurfaceMetrics` anywhere.

In `howl-render/src/surface/text.zig`:

- `SurfaceText.RenderSurfaceExecutionInput` -> `SurfaceText.SubmitExecution`
- `submitSurface()` returns submit result, not feedback.

In `howl-render/src/surface/submit_feedback.zig`:

- Remove feedback vocabulary.
- Rename/move to `howl-render/src/prepared/submit.zig` if practical.
- No `feedback` names may remain under render source after this slice.

In `prepared_surface.zig`:

- Import `submit_result.zig` for metrics output.

In `submission.zig`:

- Replace `surface_feedback` import with `submit_result`.
- Use `HowlRenderSubmitExecution` and `HowlRenderSubmitResult`.
- Use `failedSubmitResult()`, `submitResultOut()`, and `submitExecutionIn()`.
