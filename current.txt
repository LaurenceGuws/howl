Current coherence rule:

- `howl_vt_terminal_copy_surface()` and graphics item queries are separate publications.
- Surface publication is keyed by `snapshot_seq` from the visible surface copy path.
- Graphics item queries are keyed by `publication_seq` returned by `howl_vt_terminal_query_graphics_meta()`.
- Graphics publication is conservative today: any terminal dirty-generation change can advance it, not only graphics-local mutation.
- A caller that wants one coherent pair must:
  1. copy the VT surface snapshot
  2. query graphics meta
  3. use that returned graphics `publication_seq` for image/placement/payload item queries
  4. if any graphics item query fails with invalid publication, restart acquisition rather than mixing generations
- Above-VT consumers still consume only copied C-ABI truth. They do not reach into `howl-vt` directly through Zig-module structure.
