## Problem

`howl-render/src/prepared/owner.zig` is a prepared handle owner, but it currently imports `../ffi.zig` and stores C ABI retrieval status values directly. The owner should store owner-local render-surface emission truth. `howl-render/src/ffi/prepared_surface.zig` should translate that owner truth to `HowlRenderPreparedSurfaceRenderSurfaceStatus` at the C ABI boundary.

## Allowed Files

- `howl-render/src/prepared/owner.zig`
- `howl-render/src/ffi/prepared_surface.zig`
- `howl-render/src/test/ffi.zig`

Owner-local tests in `prepared/owner.zig` may be updated as needed. Do not edit `howl-render/include/howl_render.h`, build files, test roots, host code, VT, PTY, or unrelated render files.

## Required Shape

- Remove `const c = @import("../ffi.zig").c;` from `prepared/owner.zig`.
- Add exact owner-local enum in `prepared/owner.zig`:

```zig
pub const RenderSurfaceEmissionFailure = enum {
    none,
    allocation_failed,
    command_bound_overflow,
    create_bound_overflow,
    damage_bound_overflow,
    retire_bound_overflow,
    resource_bound_overflow,
    upload_bound_overflow,
    upload_bytes_overflow,
    invalid_prepared_sprite,
    missing_prepared_sprite,
};
```

- Replace `render_surface_status` with `render_surface_failure: RenderSurfaceEmissionFailure = .none`.
- Add `pub fn renderSurfaceFailure(self: *const Owner) RenderSurfaceEmissionFailure`.
- Keep `Owner.renderSurface()` returning `?*const render_surface_emitter.Surface`.
- Move C status mapping into `ffi/prepared_surface.zig` as a private function, for example `fn renderSurfaceStatus(failure: prepared_owner.RenderSurfaceEmissionFailure) c.HowlRenderPreparedSurfaceRenderSurfaceStatus`.
- `prepared_surface.renderSurface()` must return `renderSurfaceStatus(owner.renderSurfaceFailure())` when `owner.renderSurface()` is null.
- Preserve all current C-visible behavior and status values.
- Do not change `howl-render/include/howl_render.h`.

## Required Tests

- Owner-local tests in `prepared/owner.zig` must assert `RenderSurfaceEmissionFailure` values, not C constants.
- FFI tests in `howl-render/src/test/ffi.zig` must keep asserting shipped C status values and retrieval behavior.
- Mapping coverage for every `RenderSurfaceEmissionFailure` case must live at the FFI seam, not in the prepared owner.
