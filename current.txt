# Current Slice: Require Query Image Id

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after graphics query research.

## Goal

Match Kitty behavior by treating `a=q` graphics queries without lowercase `i=` as no-reply, no-mutation commands.

## Target Files

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- `a=q` with lowercase `i=` keeps existing query validation and replies keyed by that `i=`.
- `a=q` without lowercase `i=` emits no graphics protocol reply and stores no image.
- `a=q,I=...` without lowercase `i=` emits no graphics protocol reply and stores no image.
- Missing-`i=` queries do not validate payloads or emit payload-validation failures such as `EBADPNG`.

## Hard Constraints

- Do not change ABI, render, host, parser, terminal, FFI, or build files.
- Do not change valid lowercase-`i=` query behavior.
- Do not change upload, place, delete, animation, frame, direct media, indirect media, chunk lifecycle, parser validation, or quiet response handling.
- Do not change EBADPNG behavior, PNG mode behavior, zlib decompression behavior, storage quota, animation, delete/reset, composition, or generated placeholder behavior.
- Do not replace retained base64 model truth in this slice.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- `a=q` with no `i=` produces no pending output and stores no image.
- `a=q,I=31` with no lowercase `i=` produces no pending output and stores no image.
- `a=q` with invalid PNG payload and no `i=` produces no `EBADPNG` reply and stores no image.
- Existing valid `i=31,a=q` query test still returns `OK` and stores no image.

## Verification Required
