# Current Slice: Delete Window C Import Bucket

Owner: workspace root.

Purpose:

- Delete `window.c_win` as a broad SDL/OpenGL C import bucket.
- Move production SDL/OpenGL translation to build-owned C modules.
- Keep host/window ownership of SDL/OpenGL behavior without exporting a raw combined C namespace.

## Source Research

Use `host-owner-next-scratchpad.md` Slice C and the C-bucket research result as the sprint
scratchpad.

Reference findings:

- Zig 0.16 release notes move `@cImport` to build-system `b.addTranslateC` modules.
- `howl-linux-host/build.zig` already has `translateCModule()` and build-owned Howl C imports.
- Alacritty separates window/display ownership from renderer/GL platform ownership:
  - `utils/dev_references/terminals/alacritty/alacritty/src/display/window.rs`
  - `utils/dev_references/terminals/alacritty/alacritty/src/renderer/mod.rs`
- TigerBeetle rejects broad buckets and hidden ownership:
  - `utils/dev_references/zig_maturity/tigerbeetle/docs/TIGER_STYLE.md:90-147`

- new `howl-linux-host/src/window/sdl_c.h`

Required shape:

- Add build-owned translate-C modules:
  - `sdl_c` from `src/window/sdl_c.h` containing `#include <SDL3/SDL.h>`.
  - `gl_c` from `src/window/gl_c.h` containing `#include <SDL3/SDL_opengl.h>`.
- Add both imports to host modules and host integration test modules.
- Delete `pub const c_win = c` from `window/window.zig`.
- Delete production `@cImport` from `window/window.zig`.
- `window/window.zig` imports `sdl_c` for SDL window/clipboard/cursor/URL calls and `gl_c` if needed
  for GL context types/constants.
- `window/term_texture.zig`, `window/present.zig`, `window/texture.zig`, and `window/draw.zig`
  import `gl_c` directly for GL calls/types.
- `input/window.zig` and `input/input.zig` import `sdl_c` directly for SDL event/wake/timer/semaphore
  calls/types.
- Terminal files must not import a raw window C bucket. Use owner wrappers when available:
  - `InputWindow.nowNs()` for SDL ticks.
  - wrapper functions/types in `input/window.zig` for semaphores if needed.
