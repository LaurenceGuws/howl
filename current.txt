# Current Slice: Protocol V0 Prepared Fill Command Coalescing

Owner: `howl-render` protocol V0 prepared command emission.

Research inputs:

- `research/2026-05-31-howl-render-protocol-sprint.md`
- `docs/render-protocol-v0.md`

Purpose:

- Reduce `CommandBoundOverflow` for fullscreen TUIs such as `btop` without increasing
  ABI bounds and without deleting the full-RGBA oracle.
- Coalesce adjacent prepared fill commands when they are provably equivalent.

## Exact Change Scope

Allowed files:

- `howl-render/src/protocol_v0/emit.zig`
- `howl-render/src/test_protocol_proof.zig` only if an integration-level protocol proof
  is needed
- `research/2026-05-31-howl-render-protocol-sprint.md`

No render ABI changes. No host changes. No full-RGBA deletion. No V0 drawing path.

## Required Shape

- Coalesce only prepared fill-like commands: clear, background, decoration, cursor.
- Merge only horizontally adjacent rectangles with identical command kind, color,
  `y_px`, and `height_px`.
- Preserve command order across passes. Do not reorder or merge through sprites/glyphs.
- Preserve bounds: merged width must fit `u16`; otherwise append a separate command.
- Keep the existing fail-closed V0 sidecar behavior when coalescing is insufficient.

## Required Tests

- Prove adjacent same-row same-color prepared fills coalesce into one V0 command.
- Prove different color, row, height, kind, or non-adjacent rectangles do not coalesce.
- Existing overflow tests must still pass or be updated only where the intended behavior
  changed.
