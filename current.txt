## Required Product Shape

- Add a C ABI function that returns a borrowed `const HowlRenderV0Frame *` for a
  live prepared surface handle.
- The frame pointer is owned by the prepared handle and valid only while that
  handle remains live and unreleased/unconsumed.
- Null handle returns `HOWL_RENDER_CALL_MISSING_HANDLE` and writes null output when
  an output pointer is supplied.
- Null output pointer returns `HOWL_RENDER_CALL_INVALID_ARGUMENT`.
- Released or consumed handles return `HOWL_RENDER_CALL_INVALID_ARGUMENT` and null
  output.
- Successful calls do not transition lifecycle state.
- No ownership transfer to caller.

Suggested shape:

```c
int howl_render_prepared_surface_protocol_v0(
    HowlRenderPreparedSurfaceHandle prepared_surface_handle,
    const HowlRenderV0Frame **frame_out
);
```
