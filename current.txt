# Current Slice: Ignore Chunk Flag For Indirect Media

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after chunk/transmission medium research.

## Goal

Match Kitty/Ghostty behavior by ignoring `m=1` for non-direct graphics media (`t=f`, `t=t`, `t=s`) instead of rejecting the command.

## Target Files

- `howl-vt/src/test/terminal_graphics.zig`
- `howl-vt/src/kitty/graphics.zig`

## Required Behavior

- For file medium `t=f`, `m=1` is ignored and the file is loaded immediately.
- For temp-file medium `t=t`, `m=1` is ignored, the file is loaded immediately, and safe temp deletion still happens.
- For shared-memory medium `t=s`, `m=1` is ignored, the object is loaded immediately, and unlink still happens.
- Direct medium `t=d` chunk semantics remain unchanged.

## Hard Constraints

- Do not change ABI, render, host, parser, or terminal files.
- Do not change direct chunk lifecycle or parser validation.
- Do not change quiet response handling, EBADPNG behavior, storage quota, animation, delete/reset, composition, generated placeholder behavior, or PNG mode behavior.
- Do not change file permission policy, safe temp deletion rules, or shared-memory unlink policy beyond allowing `m=1` to be ignored.
- Do not add local-media chunk assembly semantics.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- File medium upload with `m=1` stores the expected payload and leaves no active upload.
- Temp-file medium upload with `m=1` stores the expected payload, deletes the safe temp file, and leaves no active upload.
- Shared-memory medium upload with `m=1` stores the expected payload, unlinks the object, and leaves no active upload.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct behavior requires local-media chunk assembly, parser changes, host/runtime changes, or ABI changes, stop and report the exact dependency instead of widening the slice.
