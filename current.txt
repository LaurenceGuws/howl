## Purpose

Add a deterministic render-side test proving that a geometry epoch change cannot be dropped as `.none` solely because VT publication source content is otherwise identical. This is the first proof slice before any host resize/upload/present harness or behavior fix.

## Allowed Files

- `howl-render/src/source/prepare_request.zig`

## Exact Test Entrypoint

- Curated root: `howl-render/src/test.zig`
- Verification command from `howl-render`: `zig build test --summary all`
- Owner-local tests may be added to `howl-render/src/source/prepare_request.zig` only because they are reached through `src/test.zig`.

## Required Shape

- Add an owner-local test in `howl-render/src/source/prepare_request.zig`.
- Use existing source test helpers or add the smallest owner-local helper needed to build `PublicationSource` values.
- Drive `PrepareRequests.acceptSource(...)` and `PrepareRequests.takePrepareRequest(...)`; do not test only `classify(...)` directly.
- Construct a prior published source at geometry epoch `1`.
- Construct a new source with the same cells/dirty metadata at geometry epoch `2`.
- Assert the geometry-changed publication is queued even if source content is otherwise equal.
- Assert `takePrepareRequest(2, submitted_token)` returns a request with `token.geometry_epoch == 2`.
- Assert the request is retained-safe for geometry change: `token.damage_kind == .full`, `token.damage_base_seq == 0`, and `allow_retained_reuse == false` when geometry invalidates retained base.
- Assert a second identical source at geometry epoch `2`, after the full geometry-safe request has been taken and no newer submitted token exists, returns `published == false`, `queued == false`, and `damage_kind == .none` only if the active source already represents the same snapshot/content at geometry epoch `2`.

## Non-Goals

- Do not modify product behavior in this slice unless the existing code cannot express the required invariant; if so, stop and report the exact failing invariant.
- Do not touch host files.
- Do not drive `Context.renderTurn()`, host GL upload, or present ack.
- Do not add a new test root.
- Do not introduce runtime/controller/manager abstractions.
- Do not change public C ABI.

## Stop Conditions

- Stop if the test requires files outside `howl-render/src/source/prepare_request.zig`.
- Stop if the test needs a duplicate test root or build wiring change.
- Stop if the required invariant contradicts current `PrepareRequests` ownership and needs design review.
- Stop if `resource_epoch` must become meaningful to prove this slice.
- Stop if the test can only be written by importing host internals or bypassing the C ABI boundary.
