# Current Slice: Validate Raw Direct Payloads

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after raw direct payload validation research.

## Goal

Match Kitty/Ghostty behavior by validating uncompressed direct raw graphics payloads (`t=d`, `c` omitted, `f=24` or `f=32`) before retaining or publishing them.

## Target Files

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- For uncompressed direct raw uploads (`t=d`, `c` omitted, `f=24` or `f=32`), validate base64 syntax.
- Decode raw payloads only for validation; retain the original base64 transport bytes for the current ABI/product behavior.
- Require decoded byte length to equal `width * height * bytes_per_pixel` where `f=24` is 3 bytes per pixel and `f=32` is 4 bytes per pixel.
- Reject zero width or height through the existing raw payload validation path.
- Preserve direct PNG (`f=100`) validation and zlib-compressed raw behavior.

## Hard Constraints

- Do not change ABI, render, host, parser, terminal, or build files.
- Do not change direct chunk lifecycle, local media behavior, parser validation, or quiet response handling.
- Do not change EBADPNG behavior, PNG mode behavior, zlib decompression behavior, storage quota, animation, delete/reset, composition, or generated placeholder behavior.
- Do not replace retained base64 model truth in this slice.
- Existing tests that use invalid raw fixtures must be corrected to valid fixture dimensions/payloads if they assert successful upload behavior.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- Valid `s=1,v=1,t=d,f=24;AAAA` stores successfully.
- Valid `s=1,v=1,t=d,f=32;AAAAAA==` stores successfully.
- Invalid base64 direct raw payload fails with graphics `EINVAL` and does not store an image.
- Decoded-length mismatch such as `s=2,v=1,t=d,f=24;QUJD` fails with graphics `EINVAL` and does not store an image.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct behavior requires replacing retained base64 model truth, parser changes, host/runtime changes, render changes, ABI changes, or broad fixture rewrites outside graphics tests, stop and report the exact dependency instead of widening the slice.
