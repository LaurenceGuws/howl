## Required Product Shape

- Implement the documented command-boundary domain exactly.
- Commands compare by zero-based index in `HowlRenderV0Frame.commands`.
- `create_seq`, `upload_seq`, and `retire_seq` must be `<= commands.count`.
- Same-frame create is visible at command indexes `>= create_seq`.
- Same-frame upload is visible at command indexes `>= upload_seq`.
- Same-frame retire makes the resource invalid at command indexes `>= retire_seq`.
- Same-frame temporary resource must satisfy `create_seq <= upload_seq` and
  `upload_seq < retire_seq` when retired.
- Command use must satisfy `create_seq <= command_index`, `upload_seq <= command_index`,
  and `command_index < retire_seq` when same-frame entries exist.
- Duplicate retire rejects.
- Missing resource and wrong generation remain distinct.
- Existing clear/fill/sprite/alpha-glyph behavior must remain unchanged.
- No heap allocation inside realization.
