## Required Product Shape

- Add a read-only V0 probe in the prepared upload/submit path.
- Call `howl_render_prepared_surface_protocol_v0()` while the prepared handle is
  live.
- Validate basic invariants:
  - status is `HOWL_RENDER_CALL_OK`.
  - frame pointer is non-null.
  - `protocol_version == HOWL_RENDER_PROTOCOL_V0_VERSION`.
  - frame render/cell/grid dimensions match prepared info.
  - every span count is `<= count_max`.
  - upload total bytes are `<= bytes_count_max`.
- Record bounded debug/accounting facts proving the host saw a valid V0 frame.
- Continue the existing full RGBA texture upload path regardless of V0 probe success
  unless the prepared handle itself is invalid.

## Required Tests

## Required Invariants

- Probe never stores the borrowed frame pointer past the submit turn.
- Probe never mutates host GL state.
- Probe never changes `uploads_committed`, prepared submit status, or present state.
- Failure accounting is bounded and explicit; no silent fallback if invariants fail.
- Full RGBA remains the actual host rendering path.
