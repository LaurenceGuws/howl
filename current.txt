# Current Slice: Protocol V0 Prepared Payload Lifetime

Owner: `howl-render` prepared surface owner memory lifetime.

Purpose:

- Stop long-running memory growth from stale prepared-handle tombstones retaining the
  full embedded V0 payload arrays after submit/release.
- Preserve stale handle safety: consumed/released prepared handles may remain as small
  tombstones until text-session destroy, but they must not retain large frame storage.

## Exact Change Scope

Allowed files:

- `howl-render/src/prepared/owner.zig`
- `howl-render/src/test_protocol_proof.zig`
- `research/2026-05-31-howl-render-protocol-sprint.md`

No ABI changes. No host changes. No V0 rendering changes. Do not delete full RGBA.

## Required Shape

- Move `V0Payload` storage out of the always-retained prepared owner tombstone.
- Allocate V0 payload only for a live prepared owner that successfully emits V0.
- Free V0 payload on `release()`, `consume()`, failed creation, and session destroy.
- `protocolV0Frame()` must return null when the live owner has no V0 payload.
- `protocolV0FrameStorageEmptyForTest()` must prove released/consumed owners retain no
  V0 payload storage.

## Required Tests

- Existing protocol proof tests pass.
- Test that release/consume clears V0 payload storage.
- Existing overflow fallback tests still prove RGBA survives when V0 is unavailable.
