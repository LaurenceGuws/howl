# Current Slice: PNG Mode Matrix VT Proof

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after PNG mode matrix research.

## Goal

Prove VT PNG normalization handles fixed RGBA, RGB, grayscale, and palette PNG fixtures as RGBA output, matching Kitty's mode-matrix intent.

## Target Files

- `howl-vt/src/test/terminal_graphics.zig`
- `howl-vt/src/kitty/graphics.zig` only if the test exposes a real PNG decode bug

## Required Behavior

- Fixed PNG fixtures for `RGBA`, `RGB`, `L`, and `P` decode to expected RGBA bytes.
- VT current-frame publication normalizes each PNG fixture to raw RGBA `format=32`, `width=5`, `height=3`, and expected base64 payload.
- Existing invalid PNG, simple PNG, and valid PNG query behavior remains green.

## Hard Constraints

- Do not change ABI, render, host, parser, or terminal files.
- Prefer tests only.
- Do not replace stb_image or add libpng.
- Do not broaden into gamma/ICC/color-management, 16-bit, interlace, APNG, or file/temp/shm lifecycle parity.
- Do not add PNG zlib support.
- Do not change decoded PNG root storage/model truth.
- Do not change indirect media lifecycle, animation, quiet, delete/reset, quota, composition, generated placeholder behavior, or EBADPNG handling.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- Add fixed inline fixtures for `RGBA`, `RGB`, `L`, and `P` PNG modes.
- For each fixture, upload a raw/RGBA root image, upload the PNG as frame 2, select frame 2, and assert `format=32`, `width=5`, `height=3`, and expected RGBA base64.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If `stb_image` differs from Kitty/libpng for these simple 8-bit fixtures, stop and report a decoder dependency instead of widening the slice.
