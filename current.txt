# Current Slice: VT Placeholder Surface Suppression Contract

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-generated-placement-transition-scratchpad.md` item 4a.

## Goal

Move Kitty Unicode placeholder glyph suppression from render to VT's host-facing surface export, while keeping VT internal placeholder truth for graphics assembly.

## Target Files

VT:

- `howl-vt/src/ffi.zig`
- `howl-vt/src/test/terminal_surface.zig`
- `howl-vt/src/test/terminal_graphics.zig` only if needed for proof reuse

Render, for verification only unless a compile blocker proves otherwise:

- `howl-render/src/frame/input.zig`

## Required Behavior

- Internal `Screen.Cell` truth remains unchanged for placeholder cells: `0x10EEEE`, combining diacritics, foreground image id, and underline placement id remain available to VT graphics assembly.
- `howl_vt_terminal_copy_surface` exports placeholder lead cells as non-rendering text cells: codepoint space, `combining_len == 0`, zeroed combining array, underline disabled, underline color default/unset, strikethrough disabled.
- Surface export preserves background behavior and still allows `applyVisibleSelection` to mark selected placeholder cells after export, so selection displays as selection over blank cells.
- Graphics publication remains unchanged: generated placeholder placements stay normal placements and `placeholder_run_count == 0`.
- No new ABI fields.

## Hard Constraints

- Do not mutate screen state or placeholder cells before VT graphics assembly.
- Do not edit render in this slice unless a compile blocker proves otherwise.
- Do not add render-side placeholder protocol handling.
- Do not add debug/raw placeholder provenance to the ABI.
- Do not special-case yazi/panes.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `zig build test` in `howl-render`
- `zig build test:unit` in `howl-linux-host`
- `git diff --check` at workspace root

Stop condition:

- If render-facing surface consumers require both raw placeholder codepoints and non-rendering text in the same C surface contract, stop and report the exact API split needed. Do not add a half-visible placeholder workaround in render.
