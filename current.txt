# Current Slice: Runtime Full RGBA Fallback Deletion

Owner: `howl-render` prepared owner and `howl-linux-host` submit backend.

Purpose:

- Delete the runtime full-RGBA presentation fallback.

## Source-Backed Problem

- V0 steady path is now proven for btop scroll: `v0_emit_status=0`, `v0_no_sidecar=0`, `no_sidecar_call_failed=0`, `v0_unsupported_shape=0`, interval `rgba_fallback=0`, and `glyph_present=10`.
- Runtime still contains full-RGBA production, storage, ABI exposure, host upload fallback, fallback counters, and docs saying fallback remains allowed.
- User requirement: stale code and compatibility shims are unacceptable; old path must be deleted, not hidden.

## Required Shape

- Normal host presentation consumes V0 sidecars only.
- Missing V0 sidecar is an explicit submit/upload failure diagnostic, never full RGBA upload.
- Unsupported V0 shape is an explicit failure diagnostic, never full RGBA upload.
- V0 upload/realization failure is an explicit failure diagnostic, never full RGBA upload.
- Full RGBA code, if retained, must be named/reachable only as test/proof oracle.
- Public runtime ABI must not advertise full-RGBA fallback resources or prepared RGBA buffers.
- Docs must say runtime is V0-only and full RGBA is oracle-only if retained.

## Required Deletions

- Delete host runtime `uploadPreparedBuffer()` fallback path.
- Delete normal host dependency on `HowlRenderPreparedSurfaceBuffer.rgba_pixels`.
- Delete or test-scope render owner runtime `rgba_pixels` production/storage.
- Delete stale `HOWL_RENDER_V0_RESOURCE_FALLBACK_RGBA` runtime contract if no oracle-only contract requires it.
- Delete/rename fallback counters and log labels that imply runtime RGBA fallback remains.
- Update docs and scratchpad record so fallback references are historical or removed.

## Required Tests

- Host test proves missing V0 sidecar cannot present via full RGBA fallback.
- Host/render tests prove unsupported V0 cannot present via full RGBA fallback.
- Protocol proof tests continue using explicit oracle path, not runtime owner RGBA fields.
- ABI constant/tests updated so stale fallback RGBA resource is gone or explicitly oracle-only.
