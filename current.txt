# Current Slice: Extract Screen Dirty State

Owner: `howl-vt`.

Purpose:

- Move dirty-row publication state in `Screen` behind a narrow `screen/dirty.zig` state owner.
- Keep `Screen` as the terminal screen mutation entrypoint.
- Preserve dirty row semantics, surface ack behavior, resize behavior, C ABI, and visible surface output.

## Source Changes

Exact files:

- `howl-vt/src/screen.zig`
- `howl-vt/src/screen/dirty.zig`
- `howl-vt/src/screen/resize.zig` only if field installation/freeing needs direct update
- `howl-vt/src/test/terminal_surface.zig` only if existing dirty behavior coverage needs exact owner assertions
- `libs.yaml` only if owner metadata needs sharper wording

Exact movement:

- Introduce `dirty.State` holding:
  - `rows: ?DirtyRows`
  - `cols_start: ?[]u16`
  - `cols_end: ?[]u16`
- Replace `Screen.dirty_rows`, `Screen.dirty_cols_start`, and `Screen.dirty_cols_end` with one
  `dirty_state: dirty.State` field.
- Keep `Screen.peekDirtyRows`, `clearDirtyRows`, `markDirtyRow`, `markDirtyCols`, `markDirtyRows`,
  and `markAllRowsDirty` as entrypoints that delegate to dirty owner behavior.
- Preserve allocation ownership: initialization and resize still allocate/free dirty column buffers
  with the screen allocator in this slice.

## Non-Goals

- Do not change C ABI.
- Do not change dirty row semantics, surface ack semantics, resize reflow behavior, or visible surface output.
- Do not move history, cursor, margins, tabs, visible cell storage, selection, parser, host, Kitty, or runtime behavior.
- Do not introduce broad `screen/state.zig`, `types.zig`, manager, controller, runtime, compatibility alias, or umbrella owner.

## Invariants

- `Screen` remains the owner entrypoint for screen mutation.
- `dirty.State` owns only dirty publication ranges and dirty column buffers.
- `dirty.State.rows` is null when there are no dirty rows or the screen has zero rows.
- Dirty column start/end buffers remain optional and row-count sized when allocated.
- `clearDirtyRows` resets dirty rows to null and resets start/end buffers exactly as before.
- `markRow`, `markCols`, `markRows`, and `markAllRows` preserve current bounds and clamping behavior.
- Resize installs new dirty buffers and frees old buffers exactly once.
- Surface ack tests keep proving dirty rows clear only through valid current snapshot ack.
