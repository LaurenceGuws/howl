## Invariants

- `Terminal` composes the publication owner and remains the external entrypoint.
- New owner owns only publication identity/ack metadata.
- `surfaceSnapshot` still derives view/dirty/selection from `screen_set.surfaceSnapshot`.
- First valid publication keeps sequence `1`.
- Changed dirty generation, scrollback offset, view start, rows, cols, or alternate-screen state changes the sequence after the first publication.
- Re-publishing the same dirty generation and view keeps the same sequence.
- `ackSurface(0)` returns false and does not clear dirty rows.
- Ack clears dirty rows only when the acked sequence equals the current publication sequence and the publication dirty generation equals current `dirty_generation`.
- Stale ack remains idempotent success and does not clear newer dirty rows.
- `libs.yaml` must not introduce a `surface` root; it records only the exact publication owner.
