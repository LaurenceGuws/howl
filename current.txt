# Current Slice: Render Placeholder-Run ABI Cleanup

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-generated-placement-transition-scratchpad.md` item 6, after host placeholder-run publication cleanup landed in `howl-linux-host` `c607a2b` and root `54d039f`.

## Goal

Remove render's public placeholder-run input contract and internal copy/validation plumbing now that VT publishes generated placeholder cells as normal graphics placements and host no longer publishes placeholder-run spans.

## Target Files

Render:

- `howl-render/include/howl_render.h`
- `howl-render/src/ffi_types.zig`
- `howl-render/src/frame/queue.zig`
- `howl-render/src/frame/surface_text_ffi.zig`
- `howl-render/src/ffi.zig`
- `howl-render/src/test_abi.zig`

Host C ABI consumer updates:

- `howl-linux-host/src/terminal/vt/surface.zig`

## Required Behavior

- Render publish/source ABI no longer includes placeholder-run count or placeholder-run spans.
- Render queue no longer stores, clones, frees, compares, validates, or logs placeholder runs.
- Render still accepts generated placeholder placements as normal placements.
- Host compiles against the updated render C ABI and no longer sets or asserts removed render placeholder-run fields.
- VT's public/internal placeholder-run proof API remains unchanged in this slice.

## Hard Constraints

- Do not edit VT in this slice unless a compile blocker proves otherwise.
- Do not reintroduce render-side Kitty placeholder parsing, placeholder drawing, diacritic handling, fg/underline image-id handling, or virtual placement placeholder semantics.
- Do not remove generated placement flags or normal placement validation.
- Do not special-case yazi/panes.
- Do not add backwards-compatible ignored placeholder-run fields to render; the point is to delete this render input contract.

## Verification Required

- `zig build test` in `howl-render`
- `zig build test:unit` in `howl-linux-host`
- `git diff --check` at workspace root

Stop condition:

- If render still needs placeholder-run data for a non-dead behavior, stop and report the exact dependency. Do not keep a half-removed ABI field or restore placeholder rendering.
