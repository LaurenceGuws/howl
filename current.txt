# Current Slice: Generated Placeholder Dirty Publication Proof

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after generated cell-ref parity research.

## Goal

Prove Howl's current on-demand generated placeholder publication has Kitty-compatible observable behavior for row/cell mutations before considering persistent generated cell refs.

## Target Files

- `howl-vt/src/test/terminal_graphics.zig`
- `howl-vt/src/kitty/graphics.zig` only if a test exposes a real generated-publication bug
- `howl-vt/src/terminal.zig` only if a test exposes a real publication invalidation bug

## Required Behavior

- Generated placements are derived from current VT/screen truth after text-grid mutations.
- Insert/delete lines over placeholder rows moves or removes generated placements coherently.
- Insert/delete characters across placeholder cells updates generated placement runs coherently.
- Clearing placeholder cells removes generated placements from publication.
- Mutating placeholder rows invalidates stale `publication_seq` queries.
- Generated placement render-order keys remain deterministic for unchanged publication content.

## Hard Constraints

- Prefer tests only. Implementation changes are allowed only for a bug proved by a new focused test.
- Do not add persistent generated ref storage.
- Do not add a new public ABI stream or change render/host code.
- Do not reintroduce render-side Kitty placeholder parsing.
- Do not solve scrollback viewport graphics publication.
- Do not change placeholder protocol decoding rules, render sorting, layer policy, or frame/quiet behavior.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- Insert lines over placeholder rows removes/moves generated placements to match the resulting screen cells.
- Delete lines over placeholder rows removes/moves generated placements to match the resulting screen cells.
- Insert/delete chars across placeholder cells updates generated placement runs.
- Clearing a row/range containing placeholders removes generated placements.
- Reusing an old `publication_seq` after placeholder row mutation is rejected.
- Generated placement render-order keys remain stable for unchanged publication content after a non-graphics meta query.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If this proof requires persistent generated refs, scrollback-aware graphics publication, ABI changes, render changes, or host policy changes, stop and report the exact dependency instead of widening the slice.
