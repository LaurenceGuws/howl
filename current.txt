## Required Contract Closure

- Define `HowlRenderV0GlyphRef.glyph_id` as a render-owned protocol identity,
  including what font/config/generation/render options it is bound to.
- Define glyph atlas resource semantics for alpha and color resources, including
  page size, page count, generation, create/update/use/retire/ack, and reuse.
- Define atlas packing: rect allocation, page-full behavior, oversized glyph
  behavior, dirty-rect versus whole-page uploads.
- Define upload formats: `ALPHA8`, `RGBA8`, whether RGB/subpixel is unsupported,
  stride/count rules, and invalid resource/format pairings.
- Define placement: `x_px/y_px` as final pixel destination or an alternative
  explicit model; include bearings, offsets, combining marks, ligatures, wide
  cells, and clipping.
- Define run splitting: rows, atlas resource changes, style/font/cursor/selection
  boundaries, and `HOWL_RENDER_V0_GLYPHS_PER_RUN_MAX` overflow.
- Define alpha/color draw semantics and whether color glyphs remain blocked.
- Define equivalence and negative tests required before product code.

## Required Invariants

- Render owns glyph identity, shaping, atlas packing, upload bytes, command
  production, damage, and protocol lifetime.
- Host owns backend resource realization and presentation.
- No backend objects enter the ABI.
- No generic scene graph.
- All counts and resources stay fixed-bound.
- Direct glyph-run implementation remains blocked until this document-only slice
  is accepted and a later worker slice promotes exact product files/tests.
