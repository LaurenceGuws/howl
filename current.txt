# Current Slice: Kitty Graphics Parser Validation

Owner: workspace root.

Sprint scope: graphics.

## Goal

Match Kitty graphics control-block parsing closely enough that malformed command metadata
is rejected before graphics state mutation.

- `utils/dev_references/terminals/kitty/kitty/graphics.h`

## Required Behavior

- Validate graphics control-block syntax before calling `State.handle` or mutating graphics state.
- Reject unknown keys, missing `=`, invalid action/delete/transmission/compression flags,
  empty integer fields, invalid integer bytes, overlarge unsigned integers, invalid signed
  integers, bad separators, and trailing incomplete fields.
- Invalid parser input must not mutate image, placement, frame, upload, or reply state.
- Remove dead `unsupported_key` state/handler plumbing if strict parse rejection makes it
  unreachable.
- Preserve existing supported command behavior for valid commands.
- Preserve existing quiet handling for valid commands.

## Required Tests

- Invalid action, delete, transmission, and compression flags fail without mutation.
- Invalid integer fields fail instead of becoming `0`.
- Unsupported or malformed control keys fail before mutation.
- Bad separators and trailing incomplete fields fail before mutation.
- Existing valid graphics tests continue to pass.

- `zig build test --summary all` in `howl-vt`
- `zig build test:regression:build --summary all` in `howl-vt`
- root `zig build`
- root `git diff --check`

Stop condition:

- If exact Kitty reply/error taxonomy for parser failures is ambiguous, stop after
