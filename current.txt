# Current Slice: Delete Terminal C Import Bucket

Owner: workspace root.

Purpose:

- Delete `howl-linux-host/src/terminal/c.zig` as a broad C import bucket.
- Follow Zig 0.16 release notes: `@cImport` is deprecated; C translation belongs in `build.zig` via `b.addTranslateC` and module imports.
- Split host C imports by owner namespace so files import only SDL/window, PTY, VT, or render C ABI as needed.

## Source Facts

- Zig 0.16.0 release notes section `@cImport Moving to Build System` shows replacing `c.zig` with a C header plus `b.addTranslateC` and `@import("c")` module imports.
- `howl-linux-host/src/terminal/c.zig` currently imports SDL, OpenGL, PTY, VT, and render in one file.
- `howl-render/include/howl_render.h` no longer imports `howl_vt.h`, so render and VT C modules can be translated separately.
- `howl-linux-host/src/window/term_texture.zig` currently reaches render C ABI through `../terminal/c.zig`, which is a false terminal dependency.
- `howl-linux-host/build.zig` already owns include paths and library linkage for SDL, PTY, VT, and render.

Required shape:

- Add build-system translate-C modules for owner-scoped imports:
  - SDL/OpenGL for window/host code if needed.
  - Howl PTY C ABI for PTY owner files.
  - Howl VT C ABI for VT owner files.
  - Howl render C ABI for render owner files and host texture code that needs render host-surface types.
- Replace `@import("terminal/c.zig").c`, `@import("../terminal/c.zig").c`, `@import("../c.zig").c`, and `@import("c.zig").c` with explicit generated C module imports.
- Delete `howl-linux-host/src/terminal/c.zig`.
- Delete `TerminalC` test export; no replacement wrapper.

## Non-Goals

- Do not change public C ABI headers.
- Do not change link dependencies except where needed for translate-C modules.
- Do not migrate unrelated `@cImport` sites outside the terminal bucket path, such as `window/window.zig`, `window/icon.zig`, or stress tools, unless required to make the owner-scoped imports work.
- Do not introduce new Zig wrapper modules around generated C imports.
- Do not add aliases or compatibility shims.
- Do not rename product ABI symbols.

## Invariants

- Host still consumes Howl PTY, VT, and render through C headers and exported C symbols only.
- No host file gains Zig-shaped imports of Howl internals.
- SDL/OpenGL calls remain host/window ownership.
- Render host surface types are imported from render C ABI, not terminal ownership.
- PTY owner files do not import render or VT C modules unless they already truly need that ABI.
- VT owner files may import VT and render C modules where they explicitly adapt VT source into render source.
