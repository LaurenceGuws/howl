# Current Slice: V0 Prepared Alpha Glyph Run Batching

Owner: `howl-render` V0 prepared alpha atlas command emission.

Purpose:

- Stop V0 sidecar emission failing with `HOWL_RENDER_V0_EMIT_COMMAND_BOUND_OVERFLOW` from one-command-per-alpha-glyph emission.
- Use the existing `DRAW_GLYPH_RUN` ABI capacity of `HOWL_RENDER_V0_GLYPHS_PER_RUN_MAX` glyph refs per command.
- Keep V0 sidecars available so the old full-RGBA runtime path can be deleted in a later explicit slice.

## Source-Backed Problem

- After alpha atlas entry-bound fix, local smoke moved from status 5 to `v0_emit_status=1`.
- `HOWL_RENDER_V0_EMIT_COMMAND_BOUND_OVERFLOW == 1`.
- `HOWL_RENDER_V0_COMMANDS_MAX == 8192`.
- `HOWL_RENDER_V0_GLYPHS_PER_RUN_MAX == 256`.
- Current alpha prepared sprite path calls `appendGlyphRef()`, which emits one `DRAW_GLYPH_RUN` command with `glyphs.count = 1` per alpha draw.
- The ABI and host validation already support glyph-run commands with up to 256 glyph refs.

## Required Shape

- Batch consecutive prepared alpha glyph refs into `DRAW_GLYPH_RUN` commands.
- Each glyph-run command must have `1 <= glyphs.count <= HOWL_RENDER_V0_GLYPHS_PER_RUN_MAX`.
- Preserve command order: any non-glyph command after sprite emission, especially cursor fills, must break batching.
- Preserve stable emitter-owned glyph storage; command spans must remain valid after publish.
- Preserve exact `CommandBoundOverflow` when batched command count still exceeds `HOWL_RENDER_V0_COMMANDS_MAX`.
- Preserve transactional emission behavior: failed emission must not mutate accepted frame/resource state.

## Required Tests

- Protocol/unit test proves multiple alpha glyph refs share one glyph-run command.
- Boundary test proves exactly `HOWL_RENDER_V0_GLYPHS_PER_RUN_MAX` refs fit in one command and the next ref starts a second command.
- Protocol proof test proves a prepared frame with more than 8192 alpha sprite draws can emit V0 with batched glyph commands when glyph storage/other bounds permit, or stops with a source-backed proof gap if glyph storage remains tied to command max.
- Existing protocol oracle/proof tests pass.
