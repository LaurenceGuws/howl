## Accepted Answer

- `runLoopTurn()` still carries too much implicit host policy in one body.
- Admission, window-event pumping, host-owned mutations, runtime progress, redraw/render intent, render, present intent, and present completion must read as explicit phases.
- Runtime `keep_running` must suppress blocking only.
- Host redraw request draining must feed only host redraw intent.
- Present completion must be named explicitly in host code, not buried in generic render flow.
