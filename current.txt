# Current Slice: Move Tab Slots Out Of Main

Owner: workspace root.

Purpose:

- Move bounded tab slot storage and active/free ordering out of `howl-linux-host/src/main.zig`.
- Keep `main.zig` as the event-loop/app dispatch owner, not the tab slot storage owner.
- Follow Ghostty/Alacritty host shape: app/event processor owns a list of terminal surfaces/windows,
  while each terminal context owns one terminal widget/session.

## Current Source Facts

- `howl-linux-host/src/main.zig:21-82` currently defines `TabSlots` inside the app loop owner.
- `TabSlots` owns:
  - `[max_tabs]TerminalContext` backing storage.
  - active tab pointer order.
  - active slot indices.
  - free slot stack.
  - active/free counts.
  - acquire, append, release, ordered-remove invariants.
- `main.zig` also owns helpers coupled to tab storage and active index:
  - `destroyTabs`
  - `activeTab`
  - `activeContext`
  - `tabIndexInRange`
  - `openTab`
  - `closeActiveTab`
  - `selectRelative`
  - `selectTab`
  - `syncTerminalFocus`
  - `tabTitles`
- `TabBar.TabIndex` and `TabBar.max_tabs` are the current tab index/capacity source.

## Source Changes

  - `howl-linux-host/src/tab_bar/slots.zig`, or
  - `howl-linux-host/src/terminal/tabs.zig`

Required shape:

- Move `TabSlots` out of `main.zig` into the chosen owner file.
- Preserve bounded arrays. Do not replace with dynamic allocation.
- Preserve `TabBar.TabIndex` and `TabBar.max_tabs` unless a compile failure proves a better minimal
  owner shape is required.

- Keep terminal creation/destruction orchestration in `main.zig` for this slice unless a small helper
  must move for slot release invariants.
- Preserve active ordering and free slot reuse semantics.
- Preserve behavior and tests.

## Invariants

- Active tab count is always `<= max_tabs`.
- Free slot count is always `<= max_tabs`.
- Acquired slot index is always `< max_tabs`.
- Appended active slot index is always `< max_tabs`.
- `items()` returns active tabs in active tab order.
- Removing an active tab preserves relative order of remaining active tabs.
- Releasing a slot makes it available for later acquire.
- Closing the last tab is still ignored by `main.zig`.
- Focus/title sync behavior remains unchanged.
