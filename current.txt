## Required Product Shape

- Add a narrow backend operation sink shape for V0 resource consequences:
  create texture, upload texture rect, retire texture.
- Add a recording sink used by tests only.
- Connect the resource store to emit operations to the sink while mutating the
  protocol-fact store fail-closed.
- Store/backend operation emission must remain bounded by V0 resource/upload/retire
  maxima and retain no borrowed frame/span/upload pointers.
- Do not create real GL textures yet; that is the next slice after the operation
  sink is accepted.

## Required Tests

Add narrow host tests with exact intent equivalent to:

- `host retained render resource store records create upload retire ops`
- `host retained render resource store emits no ops on invalid frame`
- `host retained render resource store stops when operation sink is full`

Use pure helper tests. Do not introduce GL/resource realization harnesses.

## Required Invariants

- Operation recorder capacity is fixed and explicit.
- Operation payloads copy only protocol facts and byte counts, never upload byte
  pointers.
- Invalid frames leave both store state and recorded operations unchanged.
- Existing prepared upload result and submit path remain full RGBA.
