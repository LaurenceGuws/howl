# Current Slice: Dirty Metadata Canonicalization

Owner: workspace root.

Source scratchpad:

- `render-surface-hardening-scratchpad.md`
- Promoted item: `Slice D: Dirty Metadata Canonicalization`

## Goal

Canonicalize semantically irrelevant dirty metadata before publication equality and dedupe.

Clean rows do not use `dirty_cols_start` or `dirty_cols_end`. Today those columns can carry arbitrary values and still change `samePublicationSource()` because it compares the arrays byte-for-byte. That makes render source equality depend on meaningless metadata.

## Current Bad Shape

Relevant code:

- `surface_text_ffi.dirtyRowsIn()` validates dirty-row bytes are `0` or `1`.
- `surface_text_ffi.dirtyColsIn()` duplicates dirty column arrays.
- `queue.validateDirtySource()` validates dirty rows and preserves the valid dirty-row sentinel `start_col == cols && end_col == 0`.
- `queue.samePublicationSource()` compares `dirty_rows`, `dirty_cols_start`, and `dirty_cols_end` byte-for-byte.
- `queue.classifyDirty()` ignores dirty columns on clean rows.
- Text input also ignores dirty columns on clean rows.

Problem:

- Two publications with identical cells and identical clean dirty rows can compare different solely because clean-row column metadata differs.

## Reference-Derived Rule

- Alacritty damage state models damaged vs undamaged lines explicitly; irrelevant bounds on undamaged lines do not become semantic content.
- TigerBeetle requires canonical state before equality/dedupe; compare only owner-meaningful truth.
- VT owns dirty-row truth; render owns how its retained publication source canonicalizes irrelevant metadata for equality.

## Required Contract

Canonicalization rule:

- For every row where `dirty_rows[row] == 0`, set:
  - `dirty_cols_start[row] = 0`
  - `dirty_cols_end[row] = 0`
- For every row where `dirty_rows[row] == 1`, preserve the caller-provided dirty columns exactly after validation.
- Preserve the valid dirty-row sentinel:
  - `dirty_rows[row] == 1`
  - `dirty_cols_start[row] == cols`
  - `dirty_cols_end[row] == 0`

Owner boundary:

- Canonicalization must happen before `samePublicationSource()` can compare the publication.
- Canonicalization should happen after `validateDirtySource()` accepts the publication, so invalid dirty metadata is still rejected rather than silently rewritten.
- Both ordinary `publishVtSource()` and retained-slot `commitPublishSlot()` paths must receive canonicalized source state.

## Implementation Guidance

Preferred shape:

- Add a small `canonicalizeDirtyMetadata()` helper in `queue.zig` near `validateDirtySource()` / `samePublicationSource()`.
- Call it inside `PublicationState.acceptSource()` or immediately before all paths enter classification/equality.
- Use direct row iteration.
- Assert lengths match rows before mutation.
- Do not allocate.

Avoid:

- Canonicalizing in `samePublicationSource()` only. Equality should consume canonical state, not hide non-canonical state locally.
- Canonicalizing dirty rows with `dirty_rows[row] == 1`; those spans are meaningful.
- Clamping invalid dirty columns. Invalid dirty metadata must still be rejected.

## Required Proofs

Add tests in `queue.zig` unless ABI tests are clearly smaller.

Required tests:

- clean rows with different dirty column metadata become semantically equal and dedupe as `.none`.
- canonicalization mutates clean-row column values to `0,0` in stored/queued source state.
- dirty rows preserve normal spans exactly.
- dirty rows preserve the sentinel `start_col == cols && end_col == 0` exactly.
- invalid dirty metadata is still rejected by boundary validation.
