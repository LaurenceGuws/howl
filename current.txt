## Required Spec Additions

- Numeric command kind values for clear rect, fill rect, draw glyph run, and draw
  sprite.
- Numeric damage kind values, resource kind values, and upload format values
  required by command validation.
- Clear/fill rect semantics source-backed by `prepared_buffer.drawSolidRect()`
  and `blendPixel()`.
- Command ordering semantics matching `composePreparedSurface()` pass order.
- Sprite semantics for alpha and color sprite resources, including visual bounds,
  missing-resource rejection, and alpha/color blending.
- Explicit glyph-run blocker if atlas/resource/upload semantics remain
  insufficient for implementation.
- Selected equivalence oracle cases against `prepared_buffer.compose()`:
  - full redraw with background fill and cursor/decoration fill;
  - partial row retained-base preservation;
  - partial dirty row clear for transparent backgrounds;
  - sprite alpha/color blending only if source-backed enough to test without
    font/backend dependence.

## Required Invariants

- Render owns command production, resource IDs, upload bytes, atlas packing,
  glyph identity, and damage.
- Host owns backend resource realization, event loop, wake policy, presentation,
  and swap.
- V0 is not a scene graph.
- Every public kind value has a named numeric constant before realizer tests.
- Every list stays fixed-bound by existing V0 maxima.
- Full RGBA remains only oracle/fallback until V0 emission and host consumption
  are tested.
