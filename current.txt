# Current Slice: VT Graphics Delete Selector Lifetime

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` item 4 after delete-selector research.

## Goal

Match Kitty's first-order graphics delete selector lifetime semantics without changing ABI: lowercase selectors remove refs/placements while preserving named image data, and uppercase selectors free only targeted images whose matched refs are now gone.

## Target Files

VT only:

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- Keep `howl_vt.h`, render, and hosts unchanged.
- Preserve image publication ABI and payload-copy behavior.
- `d=i,i=<id>` removes matching physical/virtual placements but keeps named image data.
- `d=I,i=<id>` removes matching placements and deletes that image only if it is now unplaced.
- `d=n,I=<number>` and `d=N,I=<number>` target only the newest image with that image number.
- `d=n` keeps named image data after removing refs; `d=N` deletes the targeted image only if now unplaced.
- `d=r` removes refs for images whose client id is in `x..y` and keeps named image data; `d=R` deletes only targeted images that become unplaced.
- Uppercase geometry selectors (`C/P/Q/X/Y/Z`) must not sweep unrelated unplaced images.
- Existing generated-placeholder, virtual-placement, quota, image-number, frame, and replacement behavior remains green.

## Hard Constraints

- Do not edit render or host.
- Do not edit `howl-vt/include/howl_vt.h`, `howl-vt/src/ffi.zig`, or `howl-vt/src/terminal.zig`.
- Do not introduce the full internal id/ref/cache rewrite.
- Do not special-case yazi/panes.
- Do not move delete selector policy to render.
- Keep the smallest correct diff.

## Required Tests

- Lowercase `d=i` removes placements but keeps named image data.
- Uppercase `d=I` removes image data only for the targeted image after refs are gone.
- `d=N,I=<number>` deletes only newest matching image-number target; older same-number image remains and becomes lookup target.
- Uppercase geometry selector does not delete an unrelated unplaced image.
- Lowercase `d=r` preserves image data while removing placements for ids in range; uppercase `d=R` deletes targeted unplaced images only.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct delete semantics require full internal ref identity or generated cell-ref storage, stop and report the exact dependency instead of widening the slice.
