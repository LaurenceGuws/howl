## Required Contract Shape

- V0 is a C ABI protocol, not a Zig internal import path.
- Render owns protocol resources, command/upload/damage production, shaping,
  glyph identity, atlas packing decisions, and protocol lifetime state.
- Host owns backend object realization, event loop, wake policy, presentation
  cadence, platform UX, and swap/present.
- Every public list has a named fixed maximum.
- Every resource has explicit create/update/use/retire/ack lifetime rules.
- No backend object crosses ABI.
- No generic scene graph.
- Full RGBA surface is fallback/test oracle only, not normal path.
- Deletion of current full-surface behavior is forbidden until equivalence and
  host-consumption tests exist.

## Minimum V0 Content To Draft

- One frame object with protocol version, snapshot token, render pixel size,
  cell size/grid size, bounded damage span, bounded upload span, bounded command
  span, bounded create span, and bounded retire span if resources are introduced.
- Host acknowledgement is host-to-render input, not render-produced frame data.
- Named bounds for max frames/snapshots in flight, max damage items per frame,
  max uploads per frame, max commands per frame, max glyphs per glyph run, max
  upload bytes per frame, and max atlas pages/resources.
- Initial commands limited to clear/fill rect, draw glyph run, and draw sprite
  only if current renderer already requires sprite raster consequences.
- Invalid-input behavior for null spans, malformed spans, invalid counts, invalid
  dimensions, stale tokens, unknown/retired resources, and out-of-order
  submit/ack.
- Required test gates before ABI skeleton, software realizer, host consumer, and
  full-surface deletion.
