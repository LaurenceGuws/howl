# Current Slice: Delete-All Visible Placement Scope

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after delete/reset edge-case research.

## Goal

Match Kitty delete-all selectors for visible physical placements: default `a=d`, `d=a`, and `d=A` must not delete retained/off-screen physical placements.

## Target Files

- `howl-vt/src/test/terminal_graphics.zig`
- `howl-vt/src/kitty/graphics.zig`

## Required Behavior

- Default `a=d` behaves like Kitty `d=a`.
- `d=a` removes visible physical placements only.
- `d=a` preserves fully scrolled-above/off-screen retained physical placements.
- `d=A` removes visible physical placements and frees image data only for images that became unplaced because of matched visible placements.
- `d=A` preserves image data for images that only have retained/off-screen placements.
- Virtual and generated/cell placeholder refs remain outside this delete-all physical-placement slice unless existing behavior already deletes them by lifetime through a matched physical parent.

## Hard Constraints

- Do not change frame deletion.
- Do not change quiet response handling.
- Do not add persistent generated cell refs.
- Do not change ABI, render, host, parser, or terminal files.
- Do not implement full visibility/layer ref machinery beyond delete-all visible physical placement scope.
- Do not change RIS/reset behavior, generated placeholder publication, render sorting, or layer policy.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- `d=a` preserves a fully scrolled-above retained physical placement.
- Default `a=d` preserves a fully scrolled-above retained physical placement.
- `d=A` preserves image data for an image that only has off-screen/retained placements.
- `d=A` removes visible physical placements and frees only images that became unplaced because of matched visible placements.
- `d=a` removes a visible parent placement and its relative descendants by lifetime.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct behavior requires persistent generated refs, full render-layer visibility state, ABI changes, render changes, or host policy changes, stop and report the exact dependency instead of widening the slice.
