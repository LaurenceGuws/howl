# Current Slice: Kitty Animation Frame Gap Semantics

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after the remaining Kitty graphics parity audit.

## Goal

Match Kitty frame-gap semantics for `a=f` animation frame loads, including the default `40` ms gap for new extra frames and preserve-on-zero behavior when editing existing frames.

## Target Files

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- For `a=f` new extra frames, `z=0` or omitted `z` stores gap `40`.
- For `a=f` new extra frames, negative `z` stores gap `0`.
- For `a=f` edits to existing extra frames, `z=0` or omitted `z` preserves the previous gap.
- For `a=f` edits to existing extra frames, nonzero `z` updates the gap and clamps negative values to `0`.
- Existing root-frame, compose, delete, render-order, placeholder, and animation-control behavior remains green.

## Hard Constraints

- Do not touch ABI, render, or host files.
- Do not edit `howl-vt/src/terminal.zig`.
- Do not change placement `z_index` semantics.
- Do not implement visibility-driven animation runtime, decoded/cache storage, or persistent generated cell refs.
- Do not change compose, frame deletion, or animation-control `a=a` behavior except to keep it green.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- New extra frame without `z=` gets gap `40`.
- New extra frame with `z=0` gets gap `40`.
- New extra frame with negative `z=-1` gets gap `0`.
- Editing an existing frame without `z=` preserves its old gap.
- Editing an existing frame with `z=0` preserves its old gap.
- Editing an existing frame with negative `z=-1` changes gap to `0`.
- Existing animation-control gap tests remain green.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If preserving old gap on omitted `z` requires parser presence bits or broader command-shape changes, stop and report the exact dependency instead of widening the slice.
