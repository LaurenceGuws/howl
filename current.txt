# Current Slice: Validate Indirect Raw Undersize

Owner: workspace root.

Sprint scope: graphics.

Promoted from `graphics-machinery-scratchpad.md` after indirect raw explicit-size research.

## Goal

Match Kitty/Ghostty behavior by rejecting uncompressed indirect raw graphics media whose loaded byte count is smaller than the declared raw image dimensions require.

## Target Files

- `howl-vt/src/kitty/graphics.zig`
- `howl-vt/src/test/terminal_graphics.zig`

## Required Behavior

- For uncompressed indirect raw uploads (`t=f`, `t=t`, or `t=s`, `c` omitted, `f=24` or `f=32`), require the loaded byte count to be at least `width * height * bytes_per_pixel` before retaining or publishing.
- Explicit `S=` smaller than the required raw byte count fails with the existing insufficient-data graphics failure path.
- Omitted `S=` valid indirect raw behavior remains unchanged.
- Safe temp deletion and shared-memory unlink behavior remain unchanged even when validation fails after reading.

## Hard Constraints

- Do not change ABI, render, host, parser, terminal, FFI, or build files.
- Do not change direct media behavior, direct chunk lifecycle, parser validation, or quiet response handling.
- Do not resolve or change `S=` larger-than-expected behavior in this slice.
- Do not change EBADPNG behavior, PNG mode behavior, zlib decompression behavior, storage quota, animation, delete/reset, composition, or generated placeholder behavior.
- Do not replace retained base64 model truth in this slice.
- Do not special-case yazi/panes.
- Keep the smallest correct diff.

## Required Tests

- File medium `t=f,S=2,s=1,v=1,f=24` against a 3-byte file fails with graphics `ENODATA` and stores no image.
- Temp-file medium `t=t,S=2,s=1,v=1,f=24` fails with graphics `ENODATA`, stores no image, and still deletes a safe temp file.
- Shared-memory medium `t=s,S=2,s=1,v=1,f=24` fails with graphics `ENODATA`, stores no image, and still unlinks the shared-memory object.
- Existing valid indirect raw tests with omitted `S=` continue to pass.

## Verification Required

- `zig build test` in `howl-vt`
- `zig build test:regression:build` in `howl-vt`
- `git diff --check` at workspace root

Stop condition:

- If correct behavior requires replacing retained base64 model truth, changing larger-than-expected `S=` behavior, parser changes, host/runtime changes, render changes, ABI changes, or broad fixture rewrites, stop and report the exact dependency instead of widening the slice.
