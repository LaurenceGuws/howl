# Current Slice: Delete Render ABI Frame Vocabulary

Owner: workspace root.

Purpose:

- Delete render ABI `Frame` vocabulary.
- Render owns VT source input, prepared render surfaces, submit execution/result,
  and submitted state. It does not own presentation frames.
- Break the ABI intentionally; do not preserve old names or aliases.

## ABI Changes

In `howl-render/include/howl_render.h`, rename without old aliases:

- `HowlRenderPreparedFrame` -> `HowlRenderPreparedSurfaceToken`
- `HowlRenderFrameLayoutResult` -> `HowlRenderLayoutResult`
- `howl_render_surface_text_derive_frame_layout` ->
  `howl_render_surface_text_derive_layout`

Keep out of this slice:

- `SurfaceText` -> `TextSession`
- `PendingState` -> `SessionWorkState`
- VT publish slot names

## Render Source Changes

In `howl-render/src/surface/tokens.zig`:

- `PreparedFrame` -> `PreparedSurfaceToken`
- `SubmittedFrame` -> `SubmittedSurfaceToken`
- `PreparedFrameWith()` -> `PreparedSurfaceTokenWith()`
- `validatePreparedFrame()` -> `validatePreparedSurfaceToken()`

In prepared/session owners:

- `pipelineFrame()` -> `preparedSurfaceToken()`
- All internal function/parameter names should stop using prepared-frame when
  they mean prepared-surface token.

In boundary files:

- `preparedFrameOut()` -> `preparedSurfaceTokenOut()`
- `preparedFrameIn()` -> `preparedSurfaceTokenIn()`
- `samePreparedFrame()` -> `samePreparedSurfaceToken()`
- Use `c.HowlRenderPreparedSurfaceToken`.

In geometry boundary:

- `deriveFrameLayout()` -> `deriveLayout()`
- Use `c.HowlRenderLayoutResult`.

In `libhowl_render.zig`:

- Export `surface_geometry.deriveLayout` as
  `howl_render_surface_text_derive_layout`.

## Host Changes

In `howl-linux-host/src/terminal/render/abi.zig`:

- Call `howl_render_surface_text_derive_layout`.
- Use `HowlRenderLayoutResult`.

Update any host uses of `HowlRenderPreparedFrame` to
`HowlRenderPreparedSurfaceToken`.
