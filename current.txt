## Purpose

Remove stale render-internal unit test names and documentation language that
teach `protocol` as a separate product, while preserving public ABI vocabulary
exactly.

## Allowed Files

- `docs/render-protocol-v0.md`
- `docs/render-api-v0.md`
- `howl-render/src/test/unit/render_api_v0_oracle.zig`
- `howl-render/src/prepared/v0_frame_emitter.zig`
- `howl-render/src/render/v0_frame_realizer.zig`
- `howl-render/src/prepared/owner.zig`
- `howl-render/src/test/ffi.zig`

No other files are in scope.

## Required Shape

- Move `docs/render-protocol-v0.md` to `docs/render-api-v0.md`.
- Rewrite doc title and prose from `render protocol` / `howl-render-protocol` /
  `protocol` product nouns to `render API V0`, `V0 frame`, `V0 resource`, or
  equivalent render-owned wording.
- Preserve all public ABI code tokens in docs, including
  `HOWL_RENDER_PROTOCOL_V0_VERSION`, `HOWL_RENDER_V0_*`, `HowlRenderV0*`,
  `protocol_version`, `protocol_v0_emit_status`, and
  `howl_render_prepared_surface_protocol_v0()`.
- Rename test strings only in the allowed render files so they describe render
  API V0, V0 frame emitter, V0 frame realizer, retained V0 frame realizer,
  prepared V0 frame, or V0 frame diagnostics.
- Preserve every test body, assertion, import, build root, and discovery path.
- Preserve public ABI spelling in headers, FFI layout assertions, exports, docs
  code spans, C snippets, diagnostics fields, and public call names.

## Non-Goals

- Do not rename public C ABI symbols, fields, exported names, header constants,
  FFI layout assertions, or public call names.
- Do not rename `src/ffi/protocol_v0.zig`.
- Do not rename `howl_render_prepared_surface_protocol_v0()`.
- Do not rename `protocol_v0_emit_status`.
- Do not rename local aliases or identifiers such as `protocol_emit`,
  `protocol_realize`, `protocol_v0_emit`, `protocolV0Frame()`, or
  `protocol_v0_sprite_resources`.
- Do not edit host code.
- Do not edit build files.
- Do not delete, filter, move, or weaken tests.
- Do not edit research files to satisfy grep gates.

## Stop Conditions

- Stop if any public ABI symbol, header field, exported name, FFI layout
  assertion, or host cimport call must change.
- Stop if the doc rewrite implies an ABI break or semantic contract change.
- Stop if host code must be edited.
- Stop if any test body, assertion, import, discovery root, or build step needs
  more than test-string renaming.
- Stop if `docs/render-api-v0.md` cannot preserve the contract facts from the
  old doc while removing separate-product `protocol` language.
