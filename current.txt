## Purpose

Move the separate render API V0 oracle/equivalence tests under the unit-test
owner so unfiltered `zig build test:unit` is the render API proof gate.

This slice does not delete the old `test:protocol-proof` build bucket. That is
Slice 2, after this slice proves unit discovery.

## Allowed Files

- `howl-render/src/test_protocol_proof.zig`
- `howl-render/src/test/unit.zig`
- `howl-render/src/test/render_api_v0_oracle.zig`

No other files are in scope.

## Required Shape

- Create `howl-render/src/test/render_api_v0_oracle.zig` as the single owner for
  render API V0 oracle/equivalence unit tests.
- Move all proof/equivalence test logic from
  `howl-render/src/test_protocol_proof.zig` into
  `howl-render/src/test/render_api_v0_oracle.zig`.
- Update `howl-render/src/test/unit.zig` to import
  `render_api_v0_oracle.zig` so unfiltered `zig build test:unit` discovers the
  tests.
- Keep `howl-render/src/test_protocol_proof.zig` only as a temporary old
  build-root wrapper while `howl-render/build.zig` remains unchanged.
- `howl-render/src/test_protocol_proof.zig` must contain no independent test
  logic after this slice.
- Do not duplicate or split proof/equivalence test ownership.

## Non-Goals

- Do not edit `howl-render/build.zig`.
- Do not delete `test:protocol-proof` or `test:protocol-proof:build` in this
  slice.
- Do not move `howl-render/src/protocol_v0/emit.zig`.
- Do not move `howl-render/src/protocol_v0/realize.zig`.
- Do not rename public ABI symbols or exported functions.
- Do not edit host code.
- Do not require filtered `zig build test:unit -- "protocol v0"` as proof.

## Stop Conditions

- Stop if moving the tests requires product-code changes.
- Stop if unfiltered `zig build test:unit` does not discover the moved tests.
- Stop if the old root needs independent test logic instead of an import-only
  wrapper.
- Stop if any file outside the allowed set must change.
