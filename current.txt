# Current Slice: Rename Render SurfaceText ABI To TextSession

Owner: workspace root.

Purpose:

- Break the render C ABI to replace the false `SurfaceText` noun with `TextSession`.
- The object is a render text session: it coordinates VT source publication, geometry,
  prepared-surface lifecycle, submitted state, retained pixels, font config, and text
  preparation.
- No aliases, no compatibility shims, no old names.

## ABI Changes

In `howl-render/include/howl_render.h`, rename without old aliases:

- `HowlRenderSurfaceText` -> `HowlRenderTextSession`
- `HowlRenderSurfaceTextHandle` -> `HowlRenderTextSessionHandle`
- `HowlRenderSurfaceTextConfig` -> `HowlRenderTextConfig`
- every `howl_render_surface_text_*` symbol -> `howl_render_text_session_*`

Keep out of this slice:

- `PendingState` -> `SessionWorkState`
- `PublishSlot` -> `VtSurfaceSlot`
- broader prepared/submit/source owner reshaping not required by the rename

## Render Source Changes

- Rename `howl-render/src/surface_text.zig` to `howl-render/src/text_session.zig`.
- Move `howl-render/src/surface/text.zig` to `howl-render/src/session/text.zig`.
- Rename internal symbols:
  - `SurfaceTextConfig` -> `TextSessionConfig`
  - `SurfaceText` -> `TextSession`
  - `SurfaceTextOwner` -> `TextSessionOwner`
  - `handle.surfaceTextOwner()` -> `handle.textSessionOwner()`
- Update all render boundary modules, tests, and imports to use the text-session noun.
- Do not create aliases for the old names.

## Host Changes

Update host call sites under `howl-linux-host/src`:

- Use `HowlRenderTextSessionHandle`.
- Use `howl_render_text_session_*` symbols.
- Rename host retained field/local variables from `surface_text` to `text_session` where
  they refer to the render session handle.

## Invariants

- No old `SurfaceText` ABI or Zig aliases remain.
- Behavior is a semantic rename only.
- Status/error behavior is unchanged.
- Init still rejects zero surface size and zero font size.
- Fallback font count remains bounded by `HOWL_RENDER_MAX_FALLBACK_FONTS`.
- Text session handle owns the same session state and prepared handle lifecycle as before.
- `HowlRenderPreparedSurfaceHandle`, submit-result, prepared-surface-token, and VT
  publish-slot vocabulary remain unchanged except for the handle parameter type/prefix.
- No `types.zig`.
- No `manager`, `controller`, `runtime`, `flow`, `pipeline`, or `queue` owner.
