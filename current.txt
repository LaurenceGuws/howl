## Alacritty Facts To Preserve

- `FairMutex.lease()` reserves the next terminal lock.
- PTY read path reads bytes before terminal state lock when possible.
- `try_lock_unfair()` is the normal PTY terminal-lock acquisition attempt.
- Forced unfair lock is only acceptable at a bounded backlog threshold.
- Locked parse/mutation work is capped (`MAX_LOCKED_READ` in Alacritty).
- Wakeup is requested only after terminal state actually changes or synchronized output requires it.

## Required Shape

- `pumpTransportSlice` must not hold `term.mutex.data` while blocking or unbounded PTY reads.
- PTY reads may happen while holding `term.mutex.lease()` but before holding `term.mutex.data`.
- Terminal feed still happens only while holding `term.mutex.data`.
- The loop must have explicit byte/read bounds and assertions on those bounds.
- Tests must cover opportunistic lock failure, forced lock threshold, and locked-work cap behavior.
