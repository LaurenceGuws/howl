# Current Slice: Render FFI Cleanup, No Duplicated C Mirrors

Owner: workspace root.

Purpose:

- Make `howl-render/include/howl_render.h` the single public C contract and
  type source for render FFI.
- Keep `howl-render/src/ffi.zig` as the public-facing C-callable
  implementation owner, but delete Zig duplicate mirrors of shipped C types.
- Preserve backend independence: render remains a C ABI state engine and does
  not own backend publication, presentation, queues, or host cadence.

## Source Files

- `howl-render/include/howl_render.h`
- `howl-render/src/ffi.zig`
- `howl-render/src/libhowl_render.zig`
- `howl-render/build.zig`
- `howl-render/src/test/ffi.zig`
- `howl-render/src/frame/publication.zig`

## Required Build Change

In `howl-render/build.zig`, add include paths to the module that compiles
`src/ffi.zig`:

- `ffi_mod.addIncludePath(b.path("include"));`
- `ffi_mod.addIncludePath(b.path("../howl-vt/include"));`

This is required because `ffi.zig` must use `@cImport` against shipped C
headers instead of mirroring C structs in Zig.

## Required FFI Change

In `howl-render/src/ffi.zig`, introduce:

```zig
const c = @cImport({
    @cInclude("howl_render.h");
});
```

references.

Delete these mirrors from `ffi.zig`:

Do not add compatibility Zig enum aliases.

## Publication Mirror Cleanup

Current `howl-render/src/frame/publication.zig` duplicates VT C types:

- `Rgb8`
- `Color`
- `RenderColorState`
- `CellFlags`
- `CellAttrs`
- `Cell`
- `SelectionPos`
- `Selection`

Preferred path:

- Delete this file as a C mirror.
- Use `c.HowlVtSurfaceCell`, `c.HowlVtRenderColorState`, and
  `c.HowlVtSelection` at the FFI publication boundary only.
- Translate immediately into semantic render-owned internal structs in the true
  surface publication owner.

Minimum acceptable path for this slice:

- Move these types to `howl-render/src/surface/publication_source.zig`.
- Rename them so they are semantic render source types, not C mirrors:
  `Rgb8 -> SourceRgb`, `Color -> SourceColor`,
  `RenderColorState -> SourceColors`, `CellFlags -> SourceCellFlags`,
  `CellAttrs -> SourceCellAttrs`, `Cell -> SourceCell`,
  `SelectionPos -> SourceSelectionPoint`, `Selection -> SourceSelection`.
- Do not preserve field-for-field C naming blindly.
- FFI conversion functions must be the only C-layout translators.

## Test Changes
