## Required Shape

- `src/display.zig` is namespace-only.
- `src/display/display.zig` owns display/present behavior currently in `terminal/texture/present.zig`.
- `src/display/frame_timer.zig` owns frame pacing behavior currently in `terminal/texture/pacing.zig`.
- `src/display/renderer.zig` is namespace-only.
- `src/display/renderer/rects.zig` owns current rect/tab-bar/scrollbar/simple textured rect drawing.
- `src/display/renderer/render_surface.zig` owns current render-surface GL resource realization/upload behavior from `terminal/texture.zig`.
- `src/display/renderer/gl_c.h` is the final translated GL C header path.
- `src/window/` is renamed to `src/window_chrome/` and contains only chrome/window-wrapper/icon behavior.
- `src/window_chrome.zig` is namespace-only.
- `src/terminal/texture.zig` is namespace-only like `howl-render/src/libhowl_render.zig`.
- `src/terminal/texture/texture.zig` does not survive as a fake draw/swap owner.
- Temporary render debugging is clearly named/bannered as temporary/removable.
- `terminal/texture/present.zig` stale relative imports of absent `draw.zig` and `layout.zig` must disappear because the file either moves to display ownership or is deleted after its contents move.
- `build.zig` dedicated render-surface/texture test root must become `src/display/renderer/render_surface.zig`, not stale `src/window/term_texture.zig`.

## Non-Goals

- No public C ABI changes.
- No compatibility aliases at old `window/*` paths.
- No renderer algorithm modernization beyond owner movement required to preserve behavior.
- No test weakening, filtering, duplicate test roots, or opportunistic side-entry test files.
- No generic bucket structs or Howl-only owner names while Alacritty shapes exist.
