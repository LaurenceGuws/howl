Accepted reviewer finding:

- The test-only Cut 2A slice is blocked because `PrepareRequests.acceptSource(...)` receives `geometry_epoch`, but `classify(...)` does not, so identical publication source can return `.none` before geometry can affect retained safety.

## Purpose

Make `PrepareRequests` account for geometry epoch changes before identical VT source content can be dropped as `.none`, and prove the behavior with an owner-local test. This remains render-side only; no host resize/upload/present harness is authorized.

## Allowed Files

- `howl-render/src/source/prepare_request.zig`

## Exact Test Entrypoint

- Curated root: `howl-render/src/test.zig`
- Verification command from `howl-render`: `zig build test --summary all`
- Owner-local tests may be added to `howl-render/src/source/prepare_request.zig` only because they are reached through `src/test.zig`.

## Required Behavior

- `PrepareRequests` must classify geometry epoch changes before `samePublicationSource(...)` can return `.none`.
- If geometry changes and there is no submitted retained base for the same geometry and required base snapshot, queue a full retained-safe prepare request.
- The resulting request must have `token.geometry_epoch` equal to the new geometry epoch.
- The resulting request must have `token.damage_kind == .full` and `token.damage_base_seq == 0`.
- The resulting request must have `allow_retained_reuse == false` when geometry invalidates retained base.
- Same-geometry identical source dedupe remains allowed after the geometry-safe active source already represents the same snapshot/content at that geometry.

## Required Test

- Add an owner-local test in `howl-render/src/source/prepare_request.zig`.
- Use existing source test helpers or add the smallest owner-local helper needed to build `PublicationSource` values.
- Drive `PrepareRequests.acceptSource(...)` and `PrepareRequests.takePrepareRequest(...)`; do not test only `classify(...)` directly.
- Construct a prior published source at geometry epoch `1`.
- Construct a new source with the same cells/dirty metadata at geometry epoch `2`.
- Assert the geometry-changed publication is queued even if source content is otherwise equal.
- Assert `takePrepareRequest(2, submitted_token)` returns a request with `token.geometry_epoch == 2`.
- Assert the request is retained-safe for geometry change: `token.damage_kind == .full`, `token.damage_base_seq == 0`, and `allow_retained_reuse == false`.
- Assert a second identical source at geometry epoch `2`, after the full geometry-safe request has been taken and no newer submitted token exists, returns `published == false`, `queued == false`, and `damage_kind == .none` only if the active source already represents the same snapshot/content at geometry epoch `2`.
