## Required Product Shape

- Add a bounded host-owned resource store for V0 resource IDs.
- Store only protocol identity/state facts in this slice: resource ID, dimensions,
  format, lifecycle state, upload accounting, and retire state.
- Apply create/upload/retire spans from a borrowed V0 frame only during the turn.
- Do not retain the frame pointer, span pointers, upload byte pointers, or command
  pointers.
- Do not allocate per frame after initialization; use fixed-capacity arrays bounded
  by `HOWL_RENDER_V0_RESOURCES_MAX`.
- Reject duplicate creates, missing resources, generation/kind mismatches, upload to
  retired resources, retire before create, and capacity overflow in store tests.
- Keep existing software oracle and resource-plan probes intact.

## Required Tests

Add narrow host tests with exact intent equivalent to:

- `host retained render resource store creates uploads retires resource`
- `host retained render resource store rejects duplicate create`
- `host retained render resource store rejects upload after retire`
- `host retained render resource store rejects missing retire`
- `host retained render resource store reports capacity overflow`

Use pure helper tests. Do not introduce GL/resource realization harnesses.

## Required Invariants

- Store capacity is exactly bounded by `HOWL_RENDER_V0_RESOURCES_MAX`.
- Slot lookup compares value, generation, and kind.
- Upload accounting validates format and byte bounds before mutating stored state.
- Retire marks host-owned state retired but does not create/delete backend objects.
- Existing prepared upload result and submit path remain full RGBA.
