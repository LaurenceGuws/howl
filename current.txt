# Current Slice: VT Graphics Decoded-Truth Internal Cleanup

Owner: howl-vt.

Sprint scope: graphics.

## Goal

Make VT decoded graphics bytes the internal image/frame/coalescing truth while preserving
the existing public base64/protocol payload ABI exactly.

## Source Findings

- Old VT base64/protocol payload query/copy APIs are public ABI compatibility and must
  remain byte-for-byte stable.
- In-tree host/render now use decoded graphics bytes end-to-end.
- VT `Image.base64_payload`, `Frame.base64_payload`, and `current_override_payload` are
  now internal compatibility-publication bytes, not product/model truth.
- Frame coalescing still decodes from legacy base64 payload fields, which keeps base64 as
  internal frame graph truth and contradicts Kitty/Ghostty decoded-byte ownership.
- Render already isolates legacy vs decoded paths with payload kind; no render cleanup
  should precede VT decoded-truth cleanup unless tests expose a render bug.

## Required Work

- VT-only, ABI-preserving.
- Separate decoded/model payload ownership from legacy compatibility payload ownership in
  naming and use.
- Stop using legacy base64/protocol payload bytes as the source for frame coalescing.
- Coalesce frames from decoded image/frame bytes.
- Preserve old ABI payload bytes for direct raw, normalized raw, zlib, indirect raw, PNG,
  and current-frame publication.
- Preserve decoded ABI metadata and payload bytes.
- Add assertions around decoded length, legacy length, and format/dimension coherence.
- Keep compatibility bytes bounded under existing retained payload limits.

## Tests Required

- Old payload copy remains byte-for-byte unchanged for direct raw.
- Decoded copy remains raw bytes for direct raw.
- PNG old payload remains original protocol/base64 bytes while decoded payload is RGBA.
- Zlib/normalized raw old payload and decoded payload remain coherent.
- Current-frame publication coalesces from decoded truth and preserves old ABI bytes.
- Stale publication and invalid image index behavior remains unchanged for old and decoded
  APIs.

## Out Of Scope

- No public ABI changes.
- No render or host changes.
- No quota/eviction redesign.
- No PNG decoder replacement.
- No persistent generated refs.
- No broad frame graph rewrite beyond decoded-truth coalescing.
- No old compatibility API removal or deprecation.
