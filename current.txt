## Invariants

- The public root curates exports only.
- Existing `howl_render_text_session_*` exported symbols keep the same names.
- `init` still rejects zero surface dimensions and zero font size.
- `init` still creates `TextSessionOwner` with `std.heap.c_allocator` and returns the owner pointer cast as the C handle.
- `deinit` still tolerates a missing handle.
- Font path, fallback path count, invalid argument, out-of-memory, and failed statuses remain identical.
- `setCursorBlinkVisible` still treats nonzero as true and returns OK after owner mutation.
- The translator calls session/text owners; it does not own session or text state.
