## Required Shape

In `xterm/c0.zig`:

- Create `pub const C0 = enum(u8)` with named handled controls:
  - `backspace = 0x08`
  - `horizontal_tab = 0x09`
  - `line_feed = 0x0A`
  - `vertical_tab = 0x0B`
  - `form_feed = 0x0C`
  - `carriage_return = 0x0D`
  - `file_separator = 0x1C`
  - `group_separator = 0x1D`
  - `record_separator = 0x1E`
  - `unit_separator = 0x1F`
  - non-exhaustive `_`
- Add `pub fn fromByte(byte: u8) C0`.
- Change `action` and `process` to accept `C0`, not raw `u8`.
- Convert parser raw control bytes at the action route boundary.

In `action/vocabulary.zig`:

- Create `pub const EraseMode = enum(u2)`:
  - `cursor_to_end = 0`
  - `start_to_cursor = 1`
  - `all = 2`
  - `scrollback = 3`
- Change `SemanticEvent` and `ScreenAction` erase payloads from raw `u2` to `EraseMode`:
  - `erase_display`
  - `erase_line`
  - `selective_erase_display`
  - `selective_erase_line`

In `xterm/csi/params.zig`:

- Change `eraseMode` to return `events.EraseMode`.
- Preserve invalid/default behavior exactly: values other than 1, 2, and 3 map to `.cursor_to_end`.

In screen erase/apply files:

- Accept and switch on `EraseMode` enum tags, not raw integers.
- Preserve all behavior, including `.scrollback` clearing scrollback for ED and no-op for EL/selective modes where mode 3 currently no-ops.

## Non-Goals

- Do not rewrite parser tables.
- Do not type OSC command identities.
- Do not type cursor style params.
- Do not touch coordinate spaces.
- Do not touch screen storage packing/style packing.
- Do not reduce `action.zig` bucket in this slice.
- Do not create `types.zig`, scalar buckets, compatibility aliases, wrappers, managers, controllers, or runtimes.
- Do not change C ABI headers, symbols, enum values, or struct layouts.

## Invariants

- Dense byte/state parser transitions remain table-driven and source-order auditable.
- Parser output may remain raw `u8`; conversion to `C0` happens at the route boundary.
- LF, VT, and FF map to line feed exactly as before.
- BS, HT, and CR map exactly as before.
- `0x1C..0x1F` legacy controls map exactly as before.
- Ignored controls still return null.
- Invalid erase modes still collapse to cursor-to-end behavior.
