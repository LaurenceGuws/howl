# Current Slice: Host V0 Glyph Patch Presentation

Owner: `howl-linux-host` V0 command materialization into the retained terminal texture.

Purpose:

- Present no-full-clear V0 frames containing fill/clear commands plus `DRAW_GLYPH_RUN` commands when the host already has a matching retained terminal texture.
- Stop classifying valid atlas-backed glyph patch sidecars as unsupported shape.
- Stop falling back to full RGBA for valid glyph patch frames.
- Preserve full RGBA fallback/oracle for unsafe patch frames.

## Exact Change Scope

Allowed files:

- `howl-linux-host/src/window/term_texture.zig`
- `howl-linux-host/src/terminal/context.zig`

No render changes. No ABI changes. No batching. No CPU/frame-pacing changes. No log removal. No full-RGBA deletion.

## Source-Backed Problem

- `protocolV0GlyphFrame()` accepts glyph frames only when command 0 is a full clear.
- `btop` scrolling produces no-full-clear frames containing fill/clear and glyph-run commands.
- `protocolV0FrameSummary()` counts those glyph commands, but `Context.uploadProtocolV0Commands()` records unsupported shape before any glyph patch presenter exists.
- User logs therefore show rising `glyph` command counts but `glyph_frame=0`, `glyph_present=0`, and steady `rgba_fallback=10`.

## Required Shape

- Add a glyph patch classifier in `term_texture.zig` that accepts only:
  - `HOWL_RENDER_V0_COMMAND_CLEAR_RECT`
  - `HOWL_RENDER_V0_COMMAND_FILL_RECT`
  - `HOWL_RENDER_V0_COMMAND_DRAW_GLYPH_RUN`
- Validate fill/clear with existing fill validation.
- Validate glyph-runs with existing glyph command validation.
- Require at least one glyph ref.
- Add a glyph patch upload wrapper backed by existing `uploadProtocolV0Commands()`.
- In `context.zig`, check glyph patch after full glyph frame and before fill-only/fill-patch unsupported recording.
- Present glyph patches only when `had_matching_surface` is true.
- Fallback remains required when the retained surface is missing/mismatched or upload validation fails.

## Required Tests

- `protocolV0GlyphFrame()` rejects no-full-clear glyph patch frames.
- `protocolV0GlyphPatch()` accepts no-full-clear fill/clear plus glyph-run frames.
- `protocolV0GlyphPatch()` rejects sprite commands and unknown commands.
- Existing host tests pass.
