# Current Slice: Dissolve Render Surface Oracle Test Bucket

Owner: `howl-render` render-surface emitter, realizer, prepared owner, and FFI test owners.

Source scratchpad:

- `research/2026-06-01-render-surface-owner-rename-sprint.md`

Accepted research cache:

- `research/cache-2026-06-01-render-real-owner-names.md`

## Problem

`howl-render/src/test/unit/render_surface_oracle.zig` is stale proof-bucket structure from the old protocol proof lane. It centralizes tests for multiple owners under an `oracle` name instead of placing tests with the smallest true owner.

## Allowed Files

- `howl-render/src/test/unit/root.zig`
- `howl-render/src/test/unit/render_surface_oracle.zig`
- `howl-render/src/prepared/render_surface_emitter.zig`
- `howl-render/src/render/render_surface_realizer.zig`
- `howl-render/src/prepared/owner.zig`
- `howl-render/src/test/ffi.zig`
- `current.txt`

No other files are in scope.

## Required Shape

- Delete `howl-render/src/test/unit/render_surface_oracle.zig`.
- Remove its import from `howl-render/src/test/unit/root.zig`.
- Move emitter-owned tests into `howl-render/src/prepared/render_surface_emitter.zig`.
- Move realizer-owned comparison tests into `howl-render/src/render/render_surface_realizer.zig` only if they test realizer behavior directly.
- Move prepared-owner lifetime/diagnostic/render-surface ownership tests into `howl-render/src/prepared/owner.zig`.
- Move FFI borrowed render-surface behavior into `howl-render/src/test/ffi.zig`.
- Do not preserve an `oracle`, `proof`, `bucket`, or aggregate test file under a new name.
- Do not weaken or delete coverage to make the move easy.
- Keep helper functions private to the owner file that uses them. Duplicate a tiny fixture helper only when sharing would create a new fake test bucket.

## Non-Goals

- No ABI changes.
- No product behavior changes.
- No host changes.
- No broad formatting-only churn outside moved tests.
- No new test root or duplicate test entrypoint.

## Stop Conditions

- Stop if a test cannot be assigned to a true owner without changing behavior.
- Stop if preserving coverage requires a new shared test bucket.
- Stop if root test wiring needs anything except owner imports already reachable through `src/test.zig`.
