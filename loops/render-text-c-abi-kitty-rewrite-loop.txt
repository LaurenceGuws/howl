Scoping statement:

- Howl is a C ABI embeddable terminal. C is the only host integration option.
- The active sprint is to rewrite the render text/font/cell path to a Kitty-derived model where the renderer owns font cell layout and glyph cell fitting consequences, then exposes only C ABI contracts to hosts.
- The sprint must remove Howl-only text ownership that fights Kitty, FreeType, HarfBuzz, and the C ABI boundary.
- The sprint must not add Zig-shaped host shortcuts, compatibility aliases, or fake narrow patches.
- Howl-owned names must not use `metrics`; names must say the real owner and consequence, such as layout, size, slot, span, baseline, decoration, glyph, sprite, atlas, surface, or cell.
- Defaults/configuration movement, including any Lua default plan, must be Kitty-derived and tested before product-code changes.
- Feature maturity must include explicit shaping proof for ligature/operator sequences such as `<->` and `!=`.
- Sprint exit requires enough Kitty text-configuration parity for the user to recreate their Kitty font/text config in Howl and visually compare text edge cases against Kitty.
- Phase 1 is the current implementation scope rewrite: C ABI-only Kitty-derived text layout, glyph fitting, sprite slot, decoration, shaping, and host surface-pixel consumption on a clean base.
- Host supplies surface pixel size; render decides how VT cells present inside the rendered surface, including cell specifics. `pixel-to-cell` must not exist as a host owner.
- C ABI symbols live under the public `howl_render` namespace; the owner segment must not be `text_layout`. Candidate owner names must be reviewed against actual render ownership before coding.
- Phase 1 proof requires repo-local Iosevka Term Nerd Font face/flavor fixtures. Arch-installed font paths may be used as a copy source, but tests must use committed assets or an accepted fixture owner with source/license/inventory receipts.
- Phase 2 is maturity/config parity after Phase 1 is clean; Lua/defaults and user's exact Kitty config do not block Phase 1 unless Phase 1 touches their owner boundary.

Non-negotiables:

- C ABI only. Hosts consume render through `include/howl_render.h` and C ABI products, not Zig internals.
- No `metrics` symbols in new Howl-owned names.
- No bucket owners, fake `Context`/`Options`/`Info` data bags, or compatibility glue.
- Render owns font-derived terminal cell facts and glyph fitting consequences.
- Hosts own platform UX, windowing, event loops, presentation cadence, backend resources, and surface consumption.
- VT owns terminal protocol state, viewport/history consequences, and terminal cell truth; render consumes prepared cell surfaces through ABI contracts.
- End-of-sprint state must be owner-true, C ABI coherent, asserted, tested, and grep-clean for stale names.
