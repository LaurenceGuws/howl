Sprint goal:

- Rip out existing Howl cursor code and port Kitty cursor code to Zig across VT, shipped ABI, render publication, draw, and host consumption consequences.
- Keep Kitty parity primary for cursor work.
- Keep Ghostty fallback-only for ownership cleanliness if full Kitty behavior cannot otherwise stay clean.

Slice queue:

- Slice 1: VT savepoint and alt-screen rewrite.
  Goal: replace stale screen-local and screen-set-local cursor save and restore owners with terminal-owned Kitty-like savepoints; port Kitty behavior for `ESC 7/8`, `CSI s/u`, `47`, `1047`, `1049`, restore-without-save, and DECRQSS `" q"`; make no-shape first-class VT truth.
- Slice 2: shipped VT ABI and render publication widening.
  Goal: carry explicit Kitty no-shape through the shipped VT C ABI and active render publication owners without reinterpretation.
- Slice 3: render draw and host consumption closure.
  Goal: close cursor parity consequences in draw owner and host consumer owners.
- Slice 4: sprint-wide proof and artifact closeout.
  Goal: rerun the curated proof surface, close receipts, and leave the sprint accountable end-to-end.

Sprint invariants:

- Save and restore is terminal-owned, not screen-owned.
- Alt-screen cursor consequences follow Kitty semantics, not copied-primary semantics.
- No-shape is explicit shape truth, not collapsed hidden visibility.
- Cursor visibility and cursor colors are not part of savepoint payload.
- Render and host remain consumers only.
- Public C ABI is the product and must change wherever cursor contract truth changes.
- Kitty parity is not weakened by Ghostty.

Sprint verification gates:

- `zig build test:unit` in `howl-vt`
- `zig build test:abi` in `howl-vt`
- `zig build test` in `howl-render`
- `timeout 300s zig build test:unit` in `howl-linux-host`

Sprint non-goals:

- Multiple cursors.
- Pointer cursor shape.
- Cursor trail redesign.
- Shell integration.
- Unrelated renderer or runtime redesign.

Sprint stop conditions:

- Stop if implementation preserves copied-primary alt-screen behavior.
- Stop if savepoint truth remains screen-owned or screen-set-owned.
- Stop if no-shape is collapsed into hidden.
- Stop if visibility or cursor colors enter the savepoint payload.
- Stop if Ghostty is used to weaken Kitty parity.
