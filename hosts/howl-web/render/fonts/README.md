# Web Nerd-symbol fallback

`SymbolsNerdFontMono-Regular.ttf` is the unmodified Nerd Fonts 3.4.0
symbols-only face used as the final Web terminal fallback after Fira Code and
Noto Sans. It does not own terminal metrics; Fira remains the primary face.

Source on the accepted Arch build host:

- package: `ttf-nerd-fonts-symbols 3.4.0-1`
- upstream: https://github.com/ryanoasis/nerd-fonts
- file: `/usr/share/fonts/TTF/SymbolsNerdFontMono-Regular.ttf`
- SHA-256: `f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60`
- size: 2,507,556 bytes

The complete Nerd Fonts package license text shipped by that package is tracked
as `NERD-FONTS-LICENSE.txt` and is also published by the Web canary as
`nerd-font-license.txt`. The font binary is copied unmodified.
